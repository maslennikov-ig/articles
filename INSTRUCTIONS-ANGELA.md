# Инструкция по публикации статей — для Анжелы

Привет, Анжела! Это инструкция, как выкладывать готовые статьи на разные платформы.
Все файлы лежат в этом репозитории, в папках по платформам. Ниже — что куда брать
и какие нюансы помнить.

---

## Базовые правила (одинаковые для всех платформ)

### 1. Где взять текст статьи

Каждый файл `.md` устроен так:

```
---
platform: habr
title: "Заголовок статьи"
tags: [...]
hubs: [...]
feed_preview: |
  Текст превью для ленты...
---

# Заголовок статьи

Основной текст статьи начинается тут...
```

- **Всё, что между двумя `---` в самом верху** — это служебная информация (метаданные).
  **Её НЕ нужно копировать в редактор платформы.** Это для меня и Игоря.
- **Тело статьи начинается после второго `---`**. Копируй именно эту часть.
- **Заголовок** — берёшь из строки `title:` (без кавычек), вставляешь в поле «Заголовок» на платформе.

### 2. Что брать из метаданных

| Поле в файле | Куда вставлять на платформе |
|--------------|------------------------------|
| `title:` | Заголовок статьи |
| `subtitle:` (если есть) | Подзаголовок / лид |
| `tags:` | Поле «Теги» |
| `hubs:` (только Habr) | Поле «Хабы» |
| `category:` (только Дзен) | Категория |
| `feed_preview:` (только Habr) | Поле «Превью для ленты» |
| `seo_keywords:` (только Дзен) | SEO-настройки, если есть |

### 3. Файлы с расширением `.bak`

Это резервные копии. **Никогда не публикуй их.** Игнорируй любой файл, заканчивающийся на `.bak`.

### 4. Картинки (обложки)

Лежат в папке `articles/pictures/<имя-статьи>/`.
В каждой такой папке несколько вариантов — выбирай **один** (лучший по качеству или
тот, что Игорь отметил), ставь как обложку статьи.

### 5. Если на платформе сложный редактор

Если редактор не понимает Markdown (например, на Дзене или VC.ru — блочный редактор),
просто копируй текст по абзацам:
- Заголовки `## Что-то` → вставляй как «Заголовок 2» на платформе
- `### Что-то` → как «Заголовок 3»
- `**жирный текст**` → выделяй жирным вручную
- Цитаты `> текст` → как блок-цитата
- Списки `* пункт` → как маркированный список

## Порядок публикации (рекомендация)

Если выкладываешь обе статьи в один день — лучше так:

1. **Сначала Habr** — это главная площадка, оттуда мы потом берём ссылку для анонсов.
2. **Затем VC.ru, TenChat, Дзен, Pikabu** — в любом порядке.
3. **В последнюю очередь — Telegram-анонс** (когда уже есть ссылка на Habr).

Между разными платформами лучше делать перерыв 1-2 часа, чтобы алгоритмы не считали
это спамом и кросспостингом.

**Идеальное время для публикации:**
- Будни: 13:00-16:00 МСК или 18:00-22:00 МСК
- Telegram-анонс — в окне 18:00-22:00 МСК (когда люди заканчивают рабочий день)

## Если что-то непонятно

Если какой-то файл не открывается, картинка не загружается или непонятно, какой
раздел статьи куда вставлять — **пиши Игорю в Telegram (@maslennikovig)**. Лучше
один раз спросить, чем выложить криво.

**Не публикуй ничего, в чём сомневаешься.** Игорь подтвердит за пять минут.

## Чек-лист перед публикацией каждой статьи

- [ ] Заголовок взят из `title:` (без кавычек)
- [ ] Тело статьи скопировано **после** второго `---`, без YAML-блока
- [ ] Теги/хабы/категория проставлены из метаданных
- [ ] Превью для ленты вставлено (если есть `feed_preview:`)
- [ ] Обложка загружена из папки `articles/pictures/<имя-статьи>/`
- [ ] Файлы `.bak` не использовались
- [ ] Markdown-разметка применена корректно (если на платформе блочный редактор)

После публикации:
- [ ] Ссылка на опубликованную статью передана Игорю (для анонса в Telegram)
- [ ] Telegram-анонс опубликован с подставленной реальной ссылкой
