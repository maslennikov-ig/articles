# Топ-50 мобильных сервисов с генеративным ИИ (по версии a16z)

Ниже представлен список из 50 самых популярных мобильных сервисов с функциями генеративного искусственного интеллекта (по количеству ежемесячных активных пользователей). Для каждого из них добавлено краткое описание функционала и наиболее популярный сценарий использования (юзеркейс).

1. **[ChatGPT](https://chatgpt.com/)** — лидер среди ИИ-ассистентов от OpenAI для решения разнообразных задач, генерации текста и кода.
   - **Кейс использования:** Быстрое написание писем, поиск ответов на сложные вопросы, генерация идей для постов или проектов.
2. **[CapCut](https://www.capcut.com/)** — видеоредактор от ByteDance, активно использующий ИИ-функции для монтажа, субтитров и эффектов.
   - **Кейс использования:** Автоматическое создание субтитров из видео, удаление фона, улучшение звука для Reels или TikTok.
3. **[Gemini](https://gemini.google.com/)** — ИИ-ассистент от Google, интегрированный в экосистему и мобильные сервисы компании.
   - **Кейс использования:** Переписывание текста (рерайтинг), быстрый поиск актуальной информации из интернета, саммаризация объемных документов в Google Drive.
4. **[Canva](https://www.canva.com/)** — платформа для графического дизайна с мощными встроенными инструментами генерации изображений (Magic Studio).
   - **Кейс использования:** Быстрое создание презентаций и картинок для постов по текстовому запросу, умное (бесследное) удаление объектов с фото.
5. **[AI Gallery](#)** — умная галерея с интеллектуальной сортировкой и редактированием фото (популярна на смартфонах Transsion).
   - **Кейс использования:** Поиск конкретных людей или событий среди тысяч фото с помощью текстового запроса (например, "кот на диване").
6. **[Picsart](https://picsart.com/)** — одно из ведущих приложений для креативного редактирования фото и видео (масса ИИ-фильтров).
   - **Кейс использования:** Замена заднего фона на фото, создание креативных аватаров с помощью ИИ-фильтров, расширение краев (дорисовка) изображения.
7. **[Doubao](https://www.doubao.com/)** — популярный генеративный ИИ-ассистент от ByteDance, ориентированный на китайский рынок.
   - **Кейс использования:** Перевод текстов, помощь в учебе (для локального рынка), быстрое написание сценариев для видео или статей.
8. **[Microsoft Edge](https://www.microsoft.com/edge)** — мобильный браузер от Microsoft, в который интегрирован ИИ-ассистент Copilot для умного поиска.
   - **Кейс использования:** Краткое изложение длинных статей в браузере за пару секунд, поиск информации с выдачей готового ответа, а не ссылок.
9. **[Meituan](https://www.meituan.com/)** — китайская супер-платформа услуг и доставки, активно внедряющая генеративный ИИ для рекомендаций.
   - **Кейс использования:** Умный подбор заведений по сложным пользовательским запросам (например: "тихое место для свидания с живой музыкой").
10. **[Yandex](https://yandex.ru/)** — приложение Яндекса с интегрированным умным помощником «Алисой» на базе YandexGPT.
    - **Кейс использования:** Наложение ИИ-перевода на видео (закадровый перевод), распознавание текстов и товаров с картинки, генерация идей через голос.
11. **[Remini](https://remini.ai/)** — сервис для улучшения качества старых и размытых фотографий с использованием нейросетей.
    - **Кейс использования:** Реставрация старых семейных фотографий, повышение четкости "шумных" портретных снимков для загрузки в соцсети.
12. **[QQ Browser](https://browser.qq.com/)** — мобильный браузер от Tencent (QQ浏览器) с набором умных инструментов для поиска.
    - **Кейс использования:** Быстрый ИИ-анализ и сканирование документов огромного объема на мобильном телефоне (для Китая).
13. **[DeepSeek](https://www.deepseek.com/)** — мощная китайская модель искусственного интеллекта и чат-бот для кодинга и сложных задач.
    - **Кейс использования:** Написание скриптов автоматизации, решение нетипичных IT и логических задач, глубокий исследовательский поиск.
14. **[Cici](https://www.ciciai.com/)** — ИИ-платформа от ByteDance (зарубежная версия для ботов-персонажей), аналог Character.ai.
    - **Кейс использования:** Разговорная практика языков с ИИ-носителем, снятие стресса в ролевой беседе с вымышленным или книжным персонажем.
15. **[Perplexity](https://www.perplexity.ai/)** — поисковая система нового поколения, генерирующая прямые ответы с цитированием надежных источников.
    - **Кейс использования:** Исследовательская работа, фактчекинг новостей, когда каждая фраза ответа ИИ подкреплена ссылкой на авторитетный ресурс.
16. **[Adobe Lightroom](https://lightroom.adobe.com/)** — профессиональный фоторедактор, использующий ИИ-модули (Generative Remove, умные маски).
    - **Кейс использования:** Моментальное и реалистичное размытие фона (Generative Blur), удаление нежелательных людей из кадра без нарушения текстуры.
17. **[Baidu AI Search](https://www.baidu.com/)** — мобильный поисковик от Baidu со встроенной генеративной моделью Ernie.
    - **Кейс использования:** Интеллектуальная агрегация результатов поиска из разных ссылок в один читаемый и структурированный текст.
18. **[Grok](https://grok.x.ai/)** — ИИ-модель от xAI, интегрированная в экосистему соцсети X.
    - **Кейс использования:** Получение свежей (актуальной) выжимки с трендов соцсети X по горячим новостям, получение ответов без жесткой цензуры.
19. **[VN (VlogNow)](https://www.vlognow.me/)** — мобильный видеоредактор с множеством интеллектуальных инструментов.
    - **Кейс использования:** Автоматическое нарезание лучших, самых динамичных моментов (highlights) из длинного видео для формата шортсов (TikTok).
20. **[Threads](https://threads.net/)** — приложение от Meta, интегрирующее различные ИИ-функции материнской компании (Meta AI).
    - **Кейс использования:** Помощь в формулировании или расширении текстовых тредов, генерация картинок "на лету" в процессе обсуждения.
21. **[Meta AI](https://www.meta.ai/)** — ИИ-ассистент от Meta, доступный в их мессенджерах и как отдельный сервис.
    - **Кейс использования:** Поиск информации прямо внутри чатов WhatsApp/Instagram, создание кастомных ИИ-стикеров по текстовому запросу для бесед.
22. **[Meitu](https://www.meitu.com/)** — китайское приложение для бьютификации и редактирования фото (генеративные маски).
    - **Кейс использования:** Превращение обычной фотографии в арт (аниме-стайл или 3D-аватар), нанесение сложного и реалистичного ИИ-макияжа.
23. **[Microsoft Copilot](https://copilot.microsoft.com/)** — мобильное приложение Copilot для генерации текста и изображений (GPT-5.4, GPT-image-1.5).
    - **Кейс использования:** Создание впечатляющих картинок (на базе GPT-image-1.5) по описанию, написание черновиков рабочих писем в официальном тоне.
24. **[Hypic](https://www.hypic.com/)** — инновационный фоторедактор от ByteDance с фокусом на глубокую ИИ-ретушь.
    - **Кейс использования:** Детализированная ретушь портретов в пару тапов (разглаживание кожи с сохранением ее структуры), продвинутая ИИ-цветокоррекция.
25. **[Seekee](#)** — азиатское ИИ-приложение, нацеленное на e-commerce.
    - **Кейс использования:** Генерация рекомендаций для селлеров, помощь в написании описаний товаров и подборе визуального контента на локальных маркетплейсах.
26. **[Notion](https://www.notion.so/)** — мобильное рабочее пространство с интеграцией Notion AI для текстов и баз данных.
    - **Кейс использования:** Автоматическое превращение скомканных черновых заметок с совещания в четкий список задач (action items), перевод док-тов.
27. **[Photomath](https://photomath.com/)** — приложение Google для решения математических задач по фотографии.
    - **Кейс использования:** Навели камеру телефона на сложное уравнение в тетради или книге — мгновенно получили пошаговое объяснение его решения.
28. **[Gauth](https://www.gauthmath.com/)** — образовательное приложение от ByteDance (Gauthmath AI) для помощи в решении ДЗ.
    - **Кейс использования:** Получение помощи и подсказок по точным наукам (математике, химии) при самостоятельной подготовке ученика к экзамену.
29. **[Learna AI](#)** — приложение-ассистент в сфере EdTech (помощь в изучении языков).
    - **Кейс использования:** Распознавание сложного текста учебника и пересказ его более простыми словами для быстрого усвоения материала.
30. **[Wink](https://wink.meitu.com/)** — приложение от Meitu для ретуширования и улучшения качества видео.
    - **Кейс использования:** Вытягивание качества "шакального" (сильно сжатого) 1080p видео до высокого разрешения и стабилизация кадра с помощью ИИ.
31. **[Facemoji](https://www.facemojikeyboard.com/)** — кастомная клавиатура с интеграцией ИИ.
    - **Кейс использования:** Мгновенная генерация уникального смешного стикера из введенного текста (text-to-emoji) перед отправкой в мессенджер.
32. **[Character.ai](https://character.ai/)** — популярнейшая платформа для общения с ролевыми ИИ-персонажами пользователей.
    - **Кейс использования:** Симуляция подготовки к собеседованию с ИИ, играющим роль придирчивого HR, или просто фэнтези ролевой отыгрыш.
33. **[Microsoft Bing](https://www.bing.com/)** — поисковое приложение со встроенным чат-ботом на базе OpenAI.
    - **Кейс использования:** Анализ и сравнение множества отзывов на товар (например наушники) с выдачей сжатого вердикта для пользователя прямо в поиске.
34. **[FaceApp](https://www.faceapp.com/)** — известнейший ИИ-редактор для фотореалистичной трансформации лиц.
    - **Кейс использования:** Применение виртуальной "улыбки" к угрюмому селфи, визуализация "себя в старости" или смена прически перед стрижкой.
35. **[NOVA](https://novaapp.ai/)** — популярный сторонний клиент для взаимодействия с ИИ-чатами.
    - **Кейс использования:** Использование функционала сразу нескольких ИИ-моделей (ChatGPT, Claude) в одном дружелюбном интерфейсе с сохранением пресетов.
36. **[YouCut](https://youcut.app/)** — мобильный видеоредактор (InShot Inc.).
    - **Кейс использования:** ИИ-функция Silence Cut: приложение само находит все "эканья" и длинные паузы в видео и автоматически их вырезает.
37. **[Polish (InShot)](https://inshot.com/)** — редактор фото от команды InShot, позволяющий удалять фоны и ставить новое окружение.
    - **Кейс использования:** Выделение себя на посредственной селфи-отправке и замена "комнатного" фона на эффектную туристическую сцену.
38. **[B612](https://b612.snow.me/)** — бьюти-камера с мощными ИИ-возможностями от корейских разработчиков.
    - **Кейс использования:** Генерация фантазийных ИИ-аватаров для Telegram на основе пакета загруженных обычных фотографий своего лица.
39. **[Photoroom](https://www.photoroom.com/)** — инструмент для селлеров: идеальное вырезание фона и генерация (ИИ-тени).
    - **Кейс использования:** Создание товарной карточки: вы фотографируете кружку на столе, ИИ все удаляет и "помещает" ее в студийное окружение с тенями, увеличивая кликабельность.
40. **[PixVerse](https://pixverse.ai/)** — платформа для качественной генерации видео (text-to-video / image-to-video).
    - **Кейс использования:** Анимация статичной картинки (например, оживить огонь на фото постера) или генерация зрелищного пейзажа по тексту для вставки B-roll в проект YouTube.
41. **[Hi Translate](https://play.google.com/store/apps/details?id=com.talpa.translate)** — умный экранный переводчик сверху приложений.
    - **Кейс использования:** Мгновенный перевод переписки в зарубежном мессенджере (например, WeChat) прямо на экране, без надобности копировать реплики или делать скриншоты.
42. **[BeautyCam](https://www.meitu.com/)** — приложение от Meitu для создания улучшенных селфи.
    - **Кейс использования:** Идеальное выравнивание тона лица, устранение бликов (кожного жира) при съемке в сложных условиях освещения клуба.
43. **[Papago](https://papago.naver.com/)** — мобильный ИИ-переводчик от южнокорейской Naver.
    - **Кейс использования:** Перевод надписей или ресторанного меню в Корее/Японии через наведение камеры, точный голосовой разговор за границей в реальном времени.
44. **[Brainly](https://brainly.com/)** — образовательный сервис с внедренными алгоритмами объяснений.
    - **Кейс использования:** Школьник/студент фотографирует текстовую задачу, загружает ее в приложение и получает расписанный пошаговый алгоритм решения, а не просто правильный ответ.
45. **[PolyBuzz](#)** — набирающее популярность ИИ-социальное приложение для ролевых бесед.
    - **Кейс использования:** Общение с умными виртуальными ИИ-компаньонами (инфлюенсерами) на разные тематики: от психологической помощи до дружеской переписки о кино.
46. **[AI Mirror](https://aimirror.com/)** — редактор, превращающий селфи в аниме, 3D и живопись (img2img).
    - **Кейс использования:** Загрузка скучного повседневного селфи и применение фильтра стиля "Studio Ghibli" или "Cyberpunk" в один клик для создания эффектного постера.
47. **[Mivi](https://play.google.com/store/apps/details?id=com.mivi.in)** — приложение (хит в Индии) для создания музыкальных статус-роликов на базе ИИ.
    - **Кейс использования:** Выбор любимых семейных фото-коллажей, применение AI-видеошаблона и получение готового клипа с 3D-переходами и музыкой для WhatsApp-Stories.
48. **[SNOW](https://snow.me/)** — умная AI-камера из ЮК, популяризировавшая реалистичные ИИ-аватары.
    - **Кейс использования:** Загрузка 10-20 своих домашних селфи для генерации модельной бизнес-фотосессии, как из профессиональной корейской фотостудии.
49. **[VivaCut](https://vivacut.app/)** — профессиональный 영상-редактор с интеграцией ИИ VFX-эффектов.
    - **Кейс использования:** Сложный мобильный монтаж (для TikTok или Instagram) с автоматическим выделением масок, наложением кинематографичных переходов и трекинга движений.
50. **[BeautyPlus](https://www.beautyplus.com/)** — известная портретная камера с ИИ-ретушью.
    - **Кейс использования:** Удаление одним движением "мешков" под глазами после бессонной ночи и автоматический подбор подходящего освещения для селфи перед отправкой друзьям.

> **Примечание:** Описание основано на инфографике топ-50 генеративных ИИ-сервисов (Gen AI Mobile Apps). Для нишевых локальных приложений ссылки могут вести только в магазины мобильных приложений (App Store / Google Play).
