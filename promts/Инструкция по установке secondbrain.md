Инструкция по установке «Agent Second Brain» (Второй мозг на Claude)
Этот проект представляет собой персонального ассистента с открытым исходным кодом, который работает как ваш «второй мозг», связывая заметки, цели и задачи с помощью ИИ.

1. Предварительные требования
Для работы системы вам понадобятся:

Claude Pro: Подписка (минимум $20/мес).

VPS-сервер: Рекомендуется за пределами РФ/РБ (например, OVH или аналоги), операционная система Ubuntu.

Аккаунт GitHub: Для хранения ваших заметок в приватном репозитории.

Deepgram API: Для транскрибации голосовых сообщений (бесплатного лимита хватает надолго).

Todoist API: Для управления списком задач.

Telegram Bot: Создается через @BotFather.

2. Подготовка сервера и окружения
Автор рекомендует использовать инструмент claude-code для автоматизации установки.

Настройка VPS:

Подключитесь к вашему новому серверу.

Установите claude-code (если он еще не установлен).

Базовая безопасность (через Claude Code):

Используйте промт для настройки сервера (создание SSH-ключей, отключение входа по паролю, настройка Firewall и Fail2Ban).

Убедитесь, что установлены необходимые пакеты: git, nodejs, npm, pm2.

3. Развертывание проекта
Создание репозитория:

Создайте на GitHub приватный репозиторий (например, my-second-brain).

Настройка SSH для GitHub:

Сгенерируйте SSH-ключ на сервере и добавьте его в настройки вашего GitHub-аккаунта (Settings -> SSH and GPG keys).

Клонирование и установка:

Склонируйте репозиторий автора.

Смените origin на ваш личный приватный репозиторий.

Установите зависимости (npm install).

4. Персонализация (Этап интервью)
Это критически важный этап. Автор рекомендует выделить 2–3 часа тишины для настройки личных файлов.

Запуск интервью в Claude Code:

Попросите Claude провести с вами интервью для заполнения файлов профиля, целей и системы.

Заполнение данных:

Будьте максимально откровенны. Расскажите о своих текущих целях, проектах, привычках и контексте жизни. Чем больше данных вы дадите на старте, тем эффективнее будет работать ассистент.

5. Настройка API и токенов
Заполните файл .env следующими данными:

Telegram Token: Токен вашего бота.

Telegram ID: Ваш личный ID в Telegram (чтобы бот отвечал только вам).

Deepgram API Key: Для обработки голоса.

Todoist API Token: Для синхронизации задач.

6. Авторизация и запуск
Авторизация Claude:

Выполните на сервере команду claude login.

Пройдите по ссылке, авторизуйтесь в браузере и вставьте код подтверждения в терминал. Это необходимо, чтобы бот мог использовать вашу подписку.

Запуск бота:

Запустите процесс через pm2 или напрямую для теста.

Проверьте статус командой /status в Telegram.

7. Использование
Заметки: Пересылайте боту текст, фото или записывайте голосовые сообщения.

Обработка дня: В конце дня нажмите кнопку «Обработать» для подведения итогов и создания связей в графе знаний.

Запросы: Используйте кнопку запроса (или команду), чтобы задать вопрос своему «второму мозгу» (например: «Что я упускаю в движении к моим годовым целям?»).

Важные советы:
Приватность: Все ваши мысли хранятся на вашем сервере и в вашем приватном GitHub. Никогда не делайте репозиторий публичным. [19:43]

Obsidian: Поскольку данные хранятся в Markdown-файлах, вы можете подключить папку с сервера к Obsidian для визуализации графа знаний. [02:35]

Удачной настройки!
