# Agent Teams: когда одного AI-агента недостаточно

Anthropic представила Agent Teams — возможность координировать команду из нескольких Claude, работающих вместе. Разбираюсь, когда это даёт ROI, а когда — просто жрёт бюджет.

## Проблема

В нашей компании работает 44 AI-агента. Основная боль: **контекстное окно конечно**. Даже с 200k токенов при анализе большого проекта упираешься в лимит.

Приходится либо сжимать историю (теряешь детали), либо запускать subagents (но они только отчитываются обратно).

## Решение

Agent Teams — это несколько экземпляров Claude с независимыми контекстами, которые:
- Общаются между собой напрямую (не через главного)
- Координируются через общий task list
- Ведут дебаты и приходят к консенсусу

## Бизнес-кейсы

### 1. Code Review (fintech, security-critical)

**До:** 1 ревьюер → 1 проход → находит 70% проблем

**После:** 3 ревьюера параллельно:
- Security Reviewer (SQL injection, XSS, auth)
- Performance Checker (N+1 queries, memory leaks)
- Test Validator (coverage, edge cases)

**Результат:** Находят 95%+ проблем. Окупается для проектов, где баг стоит дорого.

### 2. Отладка с гипотезами

**Задача:** Непонятный баг, root cause неясен.

**Подход:**
- Запускаем 5 агентов с разными гипотезами
- Они спорят и опровергают теории друг друга
- Побеждает та, которая выживает

**Результат:** От 4 часов отладки до 1 часа (3x быстрее).

### 3. Параллельная разработка модулей

**Задача:** Добавить систему уведомлений (Email, SMS, Push, Queue)

**Подход:**
- 4 teammates, каждый владеет своим модулем
- Нет конфликтов файлов
- Параллелизация 4x

**Результат:** 2-3 часа вместо дня последовательной работы.

## Экономика

**Стоимость:**
| Параметр | Subagents | Agent Teams |
|----------|-----------|-------------|
| Токены на task | 50k (~$0.15) | 250k (~$0.75) |
| Время | 4 часа | 1 час |
| Находит проблем | 70% | 95%+ |

**Важно:** Если работаете через Claude.ai с подпиской **Claude Pro** ($20/мес), лимиты значительно выше. Для активного использования Agent Teams подписка окупается — можно запускать команды без постоянного контроля за API costs.

**ROI:**
- Code review: окупается для проектов $100k+ (где баг стоит дорого)
- Отладка: 3x экономия времени
- Разработка: параллелизация 3-5x

## Ограничения

Agent Teams — экспериментальная функция:
- Выключена по умолчанию
- Один тим на сессию
- Нет resume для in-process mode
- Каждый teammate = отдельный Claude (токены x N)

**Когда НЕ использовать:**
- Рутинные задачи
- Малые проекты (overhead > польза)
- Tight budget на API costs

## Вердикт для бизнеса

**Используйте, если:**
- Code review критичен (fintech, healthcare, security)
- Отладка часто занимает дни
- Разработка модулей может идти параллельно

**Не используйте, если:**
- Бюджет на токены ограничен
- Проекты малые/средние
- Задачи последовательные
