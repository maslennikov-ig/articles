# Telegram Post: Анонс статьи про LLM-судью для образовательного контента

## Вариант 1: Короткий с главным результатом (рекомендуемый)

**$0.014 за курс вместо $80-240 на ручную проверку**

Строим платформу генерации образовательных курсов. Проблема: AI генерирует контент, но кто проверяет качество?

**Что обнаружили**:
- Валидация спецификации !== качество контента
- LLM — стохастическая система: идеальная спецификация -> галлюцинированный output
- "Педагогический дрифт": урок начинается для 5-го класса, заканчивается академическим жаргоном

**Что построили**:
- Cross-model evaluation (Qwen генерирует, DeepSeek оценивает)
- Cascading voting: 67% экономии vs blanket 3x voting
- Log-probability entropy для детекции галлюцинаций без RAG
- Targeted refinement: 20-30% стоимости полной регенерации

**Результат**:
- 80-85% согласия с экспертами
- $0.014/курс (было бы $80-240 на manual review)
- **ROI: 5,700-17,000x**

В статье — полная архитектура, рубрика оценки OSCQR, экономика и implementation roadmap.

## Вариант 2: С вопросом (для вовлечения)

**Кто проверяет качество AI-сгенерированного образовательного контента?**

Мы строим платформу генерации курсов. Stage 5 создаёт спецификацию. Stage 6 генерирует контент.

Наивная гипотеза: "Если спецификация валидна, контент качественный."

**Реальность** (после исследования):
- GPT-4 оценивает свой output на 10% выше (self-preference bias)
- Claude — на 25% выше
- LLM "дрифтует" к Wikipedia-подобной сложности во время генерации
- Люди одобряют уверенно звучащие галлюцинации (Assertiveness Bias)

**Решение**: LLM-судья с cross-model архитектурой
- Qwen генерирует -> DeepSeek оценивает (разные model families)
- Cascading voting (3-й судья только для ambiguous cases)
- Log-probability entropy как proxy для галлюцинаций
- Targeted self-refinement вместо полной регенерации

**Экономика**:
- $0.014/курс на валидацию
- vs $80-240/курс manual review
- ROI: 5,700-17,000x
- 80-85% согласия с экспертами

## Вариант 3: С проблемой (эмоциональный крючок)

**Проблема: AI галлюцинирует, а люди это одобряют**

Исследование Galileo.ai: человеческие эксперты систематически принимают уверенно написанный контент за достоверный. Профессиональный тон "продаёт" галлюцинации.

**Ситуация в нашей платформе**:
- Stage 5: валидируем спецификацию урока (цели, структура)
- Stage 6: генерируем контент по спецификации
- Вопрос: кто проверяет, что контент не галлюцинирован?

**Что нашли**:
- Self-evaluation bias: GPT-4 завышает оценку своего output на 10%, Claude на 25%
- "Педагогический дрифт": урок начинается для детей, заканчивается для PhD
- Спецификация не гарантирует качество — LLM стохастичен

**Что построили**:
- Cross-model judge (разные model families для генерации и оценки)
- OSCQR-based рубрика с weighted criteria и veto rules
- Conditional RAG: дорогая fact-checking только при высокой uncertainty
- Targeted refinement: fix конкретных секций вместо regeneration

**Результат**:
- 80-85% согласия с human experts
- $0.014/курс (ROI 5,700-17,000x vs manual review)
- Production-ready после calibration на 100 уроках
