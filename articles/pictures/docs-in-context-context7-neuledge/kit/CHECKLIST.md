# Чек-лист миграции: чистый Context7 → @neuledge (L1) + Context7 (L2)

Пробеги глазами за пять минут, прежде чем отдавать `PROMPT.md` агенту. Порядок важен: сначала разведка, потом изменения.

## Перед стартом

- [ ] Установлен Node.js, есть `npm` для глобальной установки.
- [ ] Получен ключ Context7 free, лежит в переменной окружения `CONTEXT7_API_KEY` (не в трекаемом файле).
- [ ] `.env` добавлен в `.gitignore` во всех проектах.
- [ ] Рабочее дерево чистое (есть куда откатиться, если что-то пойдёт не так).

## Этап 1 — Инвентаризация (без изменений)

- [ ] Найдены все места подключения Context7 (MCP-конфиги, `CLAUDE.md`/`AGENTS.md`/`.cursorrules`, промпты).
- [ ] Собран объединённый список «библиотека + версия» из lockfile'ов всех проектов.
- [ ] Агент остановился и показал отчёт. **Ты его прочитал и одобрил.**

## Этап 2 — Глобальный L1 (@neuledge)

- [ ] `@neuledge/context` установлен глобально.
- [ ] Сервер @neuledge зарегистрирован в клиенте **один раз** (не в каждом проекте).
- [ ] Не-реестровые либы собраны через `context add`, версия прибита к lockfile где возможно.
- [ ] Для либ с warning о малом числе секций найден правильный docs-репо (`reactjs/react.dev`, не `facebook/react`) или указан `--path`.
- [ ] `context list` показывает ожидаемый стек.

## Этап 3 — Context7 как L2

- [ ] Context7 переведён из «основного» в «fallback» (не удалён).
- [ ] Ключ берётся из env, не захардкожен.
- [ ] Учтён rate-limit (~60/час): при залповых проверках включён троттлинг.

## Этап 4 — Политика маршрутизации

- [ ] В правилах каждого проекта «Context7-only» заменено на политику двух уровней (сначала L1, потом L2-fallback).
- [ ] В правила добавлена заметка про keyword-запросы к @neuledge (доменные термины, конечный метод в цепочке).
- [ ] Записана памятка: новую частую либу — один раз `context add` + рестарт сервера.

## Этап 5 — Верификация

- [ ] Запрос по либе из стека обслуживается локально (быстро, через @neuledge).
- [ ] Запрос по заведомо отсутствующей либе уходит в Context7.
- [ ] Получена итоговая сводка: что мигрировано, что в L1, где env-ключ, что осталось сделать вручную.

## Принципы на весь процесс

- [ ] Ничего не закоммичено/запушено без твоего подтверждения (смотрел дифф).
- [ ] Каждый шаг обратим и идемпотентен.
- [ ] Шаги, которые агент не может сделать сам (рестарт MCP-клиента), вынесены в явный список «вручную».
