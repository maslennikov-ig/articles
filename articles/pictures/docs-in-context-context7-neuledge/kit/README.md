# Миграционный кит: с чистого Context7 на связку @neuledge (L1) + Context7 (L2)

Набор файлов к статье **«Context7 — стандарт для доков AI-агента. Я измерил 8 альтернатив и собрал бесплатную связку»**.

Идея связки в одном абзаце: документацию агенту подаёт двухуровневая схема. **L1 — локальный `@neuledge/context`**: основной слой, бесплатный, отвечает за ~5 мс, работает offline и без лимитов. **L2 — Context7 free как fallback**: дёргается только когда L1 не покрыл запрос — то есть на библиотеке, которой нет в локальном стеке. Каждая новая библиотека уходит в платный L2 ровно один раз, после `context add` переезжает в L1 навсегда.

## Что внутри

| Файл | Зачем |
|---|---|
| **PROMPT.md** | Нейтральный промт внедрения. Вставляешь агенту (Claude Code / Codex / Cursor) — он сам инвентаризирует проекты, ставит L1, прописывает L2 и переписывает политику маршрутизации. Главный файл кита. |
| **BENCHMARK.md** | Полная таблица всех 8 инструментов со всеми колонками (STATIC, медиана, p95, раунды, латентность, retrieval) + методология замера. |
| **FALLBACK.md** | Детальный разбор замера fallback-rate: какие либы, как считал, таблица запаса до лимита, главный механизм-вывод. |
| **CHECKLIST.md** | Чек-лист миграции по шагам — чтобы ничего не сломать вслепую. |

## С чего начать

1. Прочитай **CHECKLIST.md** — пятиминутный обзор, что вообще предстоит.
2. Открой агента в директории с твоими проектами, вставь содержимое **PROMPT.md**.
3. Агент остановится после инвентаризации и покажет план — проверь его и только потом разреши менять конфиги.
4. Если хочешь сначала убедиться, что игра стоит свеч, — глянь **BENCHMARK.md** и **FALLBACK.md**.

## Границы данных

Все цифры в `BENCHMARK.md` и `FALLBACK.md` — это **мой** замер на **моём** стеке (фронтовый lockfile: Next 16, React 19, Zod 4, Supabase JS, TanStack Query, Tailwind) одним токенайзером `tiktoken o200k_base`. Абсолют к Claude может гулять на 10–15%, на относительное сравнение это не влияет. 30% fallback в общем миксе — это **не** реальная частота, а две крайние точки замера (ядро стека 0% / новая либа 100%); твоя частота будет своя. Подробные оговорки — в самих файлах.
