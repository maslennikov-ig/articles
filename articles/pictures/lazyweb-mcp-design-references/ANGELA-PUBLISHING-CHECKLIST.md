# Памятка для Анжелы: публикация цикла «LazyWeb — референсы вместо говнодизайна»

Анжела, привет. Это статья-замерка про LazyWeb — бесплатный MCP-сервер дизайн-референсов для AI-агентов. Главная мысль: не давать агенту рисовать дизайн с нуля (получается усреднённо), а заставить его брать реальные референсы и делать 3-5 вариантов на выбор.

**Сначала прочитай раздел «⚠️ Что вставить руками» — без этих правок не публиковать.** Если что-то непонятно — пиши.

> ✅ **Статус: цикл готов целиком** — Habr + PDF-бонус + Telegram-анонс + версии для TenChat и Pikabu.

---

## Что публикуем

1. **Habr** — основная статья (~12 000 знаков, замерка с честными граблями)
2. **TenChat** — деловая версия (~4 200 знаков, для руководителей: «дизайн с нуля = переделки = деньги»)
3. **Pikabu** — народная версия (~8 400 знаков, на «ты», с самоиронией)
4. **PDF-бонус** — `lazyweb-agent-guide.pdf` (промт для агента + чек-лист), раздаётся в Telegram
5. **Telegram-анонс** — анонс Habr-статьи (4 варианта, рекомендуемый отмечен) + прикрепить PDF

Все файлы — в свежем коммите, после `git pull` будут у тебя.

В тексте дважды встречается ссылка на прошлую статью Игоря — стоит плейсхолдер `HABR-URL-CCBP`. Замени **оба** на реальный URL опубликованной статьи **«Топ-советы по Claude Code от Бориса Черни и не только»** (на профиле Игоря на Хабре).

| Где в тексте | Что за ссылка |

Не найдёшь URL — спроси Игоря. **Не оставляй битых ссылок и не выдумывай.**

- Плейсхолдер `[LINK]` → URL опубликованной Habr-статьи (из Шага 1).
