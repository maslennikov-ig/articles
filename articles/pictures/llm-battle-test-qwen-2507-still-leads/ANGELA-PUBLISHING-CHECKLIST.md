## Что публикуем

Свежий тест восьми LLM на реальных задачах: годовалый Qwen держит лидерство по деньгам, раскрученные новинки (MiniMax) выдумывают факты, дорогой премиум (Opus 4.8) недодаёт объём. Вывод — не вестись на хайп, тестировать на своих задачах.

**4 материала:**

1. **Habr** — основная статья (~22 000 знаков, технический разбор)
2. **TenChat** — деловая версия (~3 600 знаков, для руководителей: «раскрученное ≠ выгодное»)
3. **Pikabu** — народная версия (~7 500 знаков, на «ты», с самоиронией)
4. **Telegram-анонс** — анонс Habr-статьи (4 варианта, рекомендуемый отмечен) + прямая ссылка на лидерборд

Все файлы — в свежем коммите, после `git pull` будут у тебя.
