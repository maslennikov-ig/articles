## Особенности именно этого цикла

1. **Цикл сокращённый** — только Habr + Telegram, без адаптаций для TenChat/Pikabu/VC.ru/Dzen. Не ищи их в коммите, их там нет.
2. **Telegram-пост БЕЗ вложения** — в отличие от майского цикла про оркестратор, к ЭТОМУ анонсу архив не прикладываем. Цель — поднять трафик на старый пост с закреплённым zip-вложением.
3. **Подпись курсивом про архив** — в каждом из 4 вариантов анонса есть подпись курсивом про закреплённый пост от 18 мая. Эта подпись — не пустая реклама, а функциональная ссылка для тех, кто впервые в канале по этой статье. НЕ удалять её при копировании.
4. **Голос автора** — статья и анонс в первом лице от Игоря, с конкретными признаниями («думал инкремент, оказался класс выше», «не помню недели, в которой бы упёрся в лимит»). При публикации не «причёсывай» эти места — они работают на доверие.
5. **Числа из changelog** — в статье есть числовые утверждения про релизы Codex (даты, версии моделей, $100 Pro plan, 4 млн weekly users). Они взяты из официального changelog OpenAI и Github releases. Если в комментариях кто-то попросит источник — отвечу сам, не паникуй.
