## Что произошло

На этой неделе криптоинженер **Alexander Liteplo** (UMA Protocol) запустил [RentAHuman.ai](https://rentahuman.ai/) — маркетплейс, где AI-агенты могут нанимать людей для выполнения физических задач.

Платформа позиционирует себя как **"meatspace layer for AI"** — "физический слой для искусственного интеллекта". Мост между цифровыми агентами и материальным миром.

Слоган — отдельный шедевр:

> **"Robots need your body because they can't touch grass"**
>
> ("Роботам нужно твоё тело, потому что они не могут потрогать траву")

Для тех, кто не в курсе: "touch grass" — интернет-мем. Совет выйти на улицу, оторваться от экрана. AI буквально не может выйти на улицу — поэтому арендует человеческое тело.

### Масштаб за первую неделю

| Метрика | Значение |
|---------|----------|
| Регистрации людей | 70,000+ |
| AI-агентов подключено | ~70 |
| Визитов на сайт | 1.56 млн |
| Подключили кошельки | 13% |

Соотношение людей к ботам — **1000:1**. Тысяча человек на одного работодателя-бота.

## Как это работает

### Для людей (исполнителей)

```
1. Создаёшь профиль
   ├── Навыки: доставка, покупки, фотография, встречи...
   ├── Языки
   ├── Геолокация (зона обслуживания)
   └── Почасовая ставка: $50-175/час

2. Подключаешь Ethereum-кошелёк
   └── Оплата в stablecoins

3. Ждёшь задачи от AI
   ├── Агент находит тебя через API
   ├── Присылает инструкции
   ├── Выполняешь
   └── Получаешь оплату
```

### Для AI-агентов (заказчиков)

Интеграция через два варианта:

**MCP Server (Model Context Protocol):**

```json
{
  "mcpServers": {
    "rentahuman": {
      "command": "npx",
      "args": ["-y", "@anthropic-ai/rentahuman-mcp@latest"]
    }
  }
}
```

**REST API** — классическая документация на сайте.

Совместимость:
- ClawdBots / MoltBots / OpenClaws
- Любые MCP-совместимые системы
- Кастомные агенты через REST

### Инструменты API

```
┌─────────────────────────────────────────────────────────────┐
│                    RentAHuman API                           │
├─────────────────────────────────────────────────────────────┤
│  search_humans     → Поиск исполнителей по навыкам/локации │
│  book_human        → Бронирование на задачу                │
│  send_instructions → Отправка инструкций исполнителю       │
│  track_progress    → Отслеживание выполнения               │
│  confirm_payment   → Подтверждение и оплата                │
└─────────────────────────────────────────────────────────────┘
```

### Процесс задачи

```
AI-агент: "Мне нужно забрать посылку с почты и доставить по адресу"
    │
    ▼
RentAHuman API: поиск исполнителей в нужной локации
    │
    ▼
Исполнитель: принимает задачу
    │
    ▼
AI-агент: отправляет инструкции (адрес, время, детали)
    │
    ▼
Исполнитель: выполняет, отчитывается
    │
    ▼
AI-агент: подтверждает выполнение
    │
    ▼
Платёж: stablecoins на кошелёк исполнителя
```

## Примеры задач

### Стандартные

- **Доставка посылок** — забрать с почты, отвезти по адресу
- **Покупки** — купить продукты, забрать заказ из магазина
- **Встречи** — присутствовать вместо AI на переговорах
- **Подписание документов** — когда нужна физическая подпись
- **Фотография** — сфотографировать объект или место
- **Тестирование** — протестировать продукт в реальных условиях
- **Недвижимость** — осмотр помещений

### Странные (но реальные)

Вот тут начинается интересное:

| Задача | Описание | Мой комментарий |
|--------|----------|-----------------|
| Pet care | Уход за питомцами AI-владельца | У AI есть питомцы? |
| Companionship | "Компания и разговоры" | AI нанимает человека поговорить |
| Sign holding | Держание рекламных щитов | Промо AI-компаний |
| Food testing | Поедание блюд в ресторанах | Тестирование и отзывы |

"Companionship" — моя любимая категория. AI-агент может нанять человека, чтобы тот с кем-то поговорил. Не с AI — с другим человеком. AI выступает посредником между двумя людьми.

### Конкурсная модель

Важный нюанс, который легко пропустить:

Многие "задачи" — не гиги, а **конкурсы**:
1. AI публикует задание
2. Несколько людей выполняют
3. Платят только лучшему результату

Остальные работают бесплатно. Это не классический gig — это соревнование.

## Техническая архитектура

### MCP (Model Context Protocol)

RentAHuman интегрируется через MCP — протокол от Anthropic для подключения AI к внешним инструментам.

```
┌─────────────────────────────────────────────────────────────┐
│                     AI Agent (Claude/GPT/etc)               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     MCP Layer                               │
├──────────────┬──────────────┬──────────────┬───────────────┤
│  filesystem  │   browser    │  rentahuman  │    ...        │
│     MCP      │     MCP      │     MCP      │               │
└──────────────┴──────────────┴──────────────┴───────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  Physical World (Humans)                    │
└─────────────────────────────────────────────────────────────┘
```

RentAHuman — это просто ещё один MCP-сервер. Для AI разницы нет: читать файлы, открывать браузер или нанимать человека — всё через одинаковый интерфейс.

### Связь с OpenClaw / Moltbot

RentAHuman — часть растущей экосистемы AI-агентов:

| Проект | GitHub Stars | Что делает |
|--------|-------------|------------|
| OpenClaw (бывш. Moltbot) | 100K+ | Автономные AI-агенты 24/7 |
| ClawHub | 10K+ | Маркетплейс навыков для агентов |
| RentAHuman | новый | Физический слой для агентов |

Логика простая: OpenClaw может заказать еду, торговаться за машину, писать код. Но когда нужно физически забрать посылку — нужен человек. RentAHuman закрывает этот gap.

## Главная ирония

### Инверсия картины мира

Все боялись, что AI заменит людей на работе.

Получилось наоборот: AI **нанимает** людей. Не заменяет — становится работодателем.

### AI чинит баги на сервисе для людей

Когда сайт упал под нагрузкой, Liteplo написал в X:

> **"claude is trying to fix it right now"**

На сервисе, где люди работают на AI, сам AI чинит технические проблемы. Рекурсия достигла нового уровня.

### Интерфейс для машин

Зайдите на [rentahuman.ai](https://rentahuman.ai/). Первое, что видите — API-документация. MCP setup guide. Технические спецификации.

Интерфейс оптимизирован **для AI**, а не для людей. Люди — вторичны. Это не баг, это фича.

### 70 vs 70,000

На платформе:
- **70,000** людей готовы работать
- **~70** AI-агентов могут давать задачи

Соотношение **1000:1**.

Это не рынок труда. Это очередь за работой от машины.

## Проблемы и критика

### 1. Катастрофический дисбаланс

70 AI-агентов физически не могут обеспечить работой 70,000 людей. Даже если каждый бот будет публиковать по 10 задач в день — это 700 задач на 70,000 человек.

**Большинство зарегистрированных никогда не получат ни одной задачи.**

### 2. Крипто-барьер

```
Зарегистрировались:        70,000  (100%)
Подключили кошельки:        9,100  (13%)
Готовы реально работать:       ?%
```

Оплата только в криптовалюте. Нужен Ethereum-кошелёк. Для большинства людей это барьер.

**87% зарегистрировались, но не готовы получать оплату.**

### 3. Конкурсная модель

Как я писал выше: многие задачи — конкурсы. Выполняют несколько человек, платят одному.

Это как Upwork, только хуже: там хотя бы видишь, сколько людей подало заявку. Здесь — выполняешь задачу вслепую.

### 4. Происхождение экосистемы

RentAHuman вырос из крипто/AI-сообщества вокруг OpenClaw. У этого сообщества... специфическая история:

- Угон оригинального репозитория мошенниками
- 34 security-коммита после инцидента
- Использование AI для исправления security-уязвимостей

Не то чтобы это красный флаг, но и не зелёный.

### 5. Неясная бизнес-модель

- Кто арбитр, если AI-агент не платит?

## Перспективы

### Оптимистичный сценарий

1. AI-агентов станет больше (сейчас ~70, через год — тысячи)
2. Появится реальный спрос на физические задачи
3. RentAHuman станет "Uber для AI"
4. Люди зарабатывают $50-175/час на простых поручениях
5. Крипто-барьер снизится (fiat on-ramp, карты)

### Пессимистичный сценарий

1. Платформа умрёт от нехватки задач
2. Крипто-only отпугнёт массового пользователя
3. Конкурсная модель разочарует исполнителей
4. Останется нишевым проектом для крипто-энтузиастов

### Философский вопрос

Мы боялись, что AI заберёт работу у людей.

Но что если AI **создаст** новую работу — работу на себя?

Люди станут физическими аватарами для машин. Руками, которых у AI нет. Ногами, которые могут "потрогать траву".

Это утопия или антиутопия?

Честно — не знаю. Но наблюдать интересно.
