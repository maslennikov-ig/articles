<spoiler title="TL;DR — для нетерпеливых">

**Что это:** Moltbot (ex-Clawdbot, ex-OpenClaw) — open-source AI-агент, работающий 24/7 на вашем сервере.

**Отличие от ChatGPT:** Это не чат-бот. Агент имеет доступ к инструментам (браузер, почта, API) и выполняет действия автономно.

## Что такое AI-агент и чем он отличается от ChatGPT

Признаюсь: когда я впервые услышал про Moltbot, подумал "ещё один чат-бот". Ошибся.

**ChatGPT** — это чат. Вы пишете, он отвечает текстом. Даже если напишет "я заказал пиццу" — никакой пиццы не будет.

**AI-агент** — это программа, которая:
1. Имеет доступ к инструментам (браузер, файловая система, API)
2. Может выполнять действия автономно
3. Работает в фоне без постоянного контроля

## Почему это бесплатно (и в чём подвох)

Подвоха нет. MIT лицензия — бери и пользуйся.

**Бесплатно:**
- Moltbot (сам агент)
- 700+ готовых скиллов
- Документация и поддержка сообщества

**Платно:**
- API для "мозгов" (Anthropic/OpenAI): $25-150/мес в зависимости от нагрузки

**Альтернатива:**
Можно использовать локальные модели через Ollama (Llama 3, Mistral). Тогда $0, но качество ниже — для простых задач хватит.

| Уровень использования | Примеры задач | Стоимость API/мес |
|----------------------|---------------|-------------------|
| Лёгкий | Напоминания, календарь | ~$25 |
| Средний | Почта, рисёрч, автоматизация | ~$50-80 |
| Активный | Кодинг, многоагентность | ~$100-150 |

Для сравнения: личный ассистент стоит от 50,000₽/мес.

### 🏠 Личная эффективность (17 сценариев)

**1. Утренний брифинг**

Агент собирает данные из нескольких источников и генерирует сводку:

```javascript
// Пример конфига утреннего брифинга
{
  "sources": [
    { "type": "weather", "api": "yandex-weather", "city": "Moscow" },
    { "type": "calendar", "api": "google-calendar" },
    { "type": "tasks", "api": "todoist" },
    { "type": "news", "channels": ["@meduzalive", "@tinkoffjournal"] }
  ],
  "output": {
    "channel": "telegram",
    "time": "07:00",
    "format": "voice" // или "text"
  }
}
```

**2. Автозаказ еды**

Триггер: первое сообщение "Доброе утро" или данные с трекера сна (Oura Ring, Apple Health).

```javascript

{
  "skill": "food-order",
  "provider": "yandex-eda", // или "samokat", "delivery-club"
  "trigger": "wake-up",
  "default_order": "saved-favorite",
  "payment": "saved-card"

```

**3-4. Сортировка почты + черновики ответов**


**5. Голосовые заметки → структурированные задачи**

Вы надиктовываете в Telegram, агент транскрибирует через Whisper и структурирует:

```
Вход: "Надо не забыть позвонить Васе насчёт проекта,
       ещё купить резину до зимы и дописать презентацию"

Выход (в Notion):
- [ ] Позвонить Васе по проекту @today
- [ ] Купить резину @before:winter
- [ ] Дописать презентацию @today
```

**6. "Второй мозг" — поиск по всему**

Все заметки, документы, чаты индексируются в векторную БД. Можно спросить: "О чём мы договорились с клиентом X полгода назад?" — агент найдёт.

**7-11. Календарь, напоминания, Kanban, подписки, здоровье**

Типовые интеграции: Google Calendar, Todoist, Trello, Apple Health. Конфиги аналогичны примерам выше.

## Установка: пошаговое руководство

### Требования

- Node.js 22+
- API ключ (Anthropic или OpenAI)
- Telegram бот (создаётся через @BotFather)

### Вариант 1: Локально (для тестов)

```bash
# Установка
npm install -g moltbot@latest

# Интерактивная настройка
moltbot onboard --install-daemon
```

Мастер запросит:
1. API ключ (Anthropic/OpenAI)
2. Telegram токен
3. Выбор каналов связи

### Вариант 2: На сервере (24/7)

**Шаг 1. Аренда VPS**

Любой хостинг: Timeweb, Aeza, Selectel. Минимальный тариф (1 ядро, 2GB RAM) достаточно. Стоимость: 200-500₽/мес.

**Шаг 2. Подключение и установка**

```bash
# Подключение
ssh root@your-ip-address

# Обновление системы
apt update && apt upgrade -y

# Установка Node.js 22
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs

# Проверка
node -v  # должно быть v22.x.x

# Установка Moltbot
npm install -g moltbot@latest
moltbot onboard --install-daemon
```

**Шаг 3. Вечный запуск через PM2**

```bash
# Установка PM2
npm install -g pm2

# Запуск
pm2 start moltbot --name "moltbot"

# Сохранение для автозапуска
pm2 save
pm2 startup
```

**Обновление:**

```bash
npm update -g moltbot
pm2 restart moltbot
```

Честно:

| Ограничение | Детали |

## Disclaimer: Expected Pushback

Понимаю, что статья может вызвать вопросы:

**"Это же просто обёртка над API?"**

Да. Но обёртка с 700+ готовыми скиллами, интеграциями и автономностью. Писать это с нуля — месяцы работы.

**"Зачем, если есть n8n/Zapier?"**

n8n/Zapier — это no-code автоматизация по триггерам. Moltbot — это агент с reasoning, который может сам принимать решения и выполнять сложные цепочки.

**"$100/мес за API — дорого"**

Личный ассистент стоит от 50,000₽/мес. $100 за робота, работающего 24/7 — это дёшево.

**"Prompt Injection — это реальная угроза"**

Да. Не давайте агенту права на критичные действия (переводы денег, открытие замков). Используйте allowlists.

Если знаете лучшие решения — пишите в комментариях. Я не претендую на истину в последней инстанции.
