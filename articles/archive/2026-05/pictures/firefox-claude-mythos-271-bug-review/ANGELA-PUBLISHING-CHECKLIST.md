# Памятка для Анжелы: публикация цикла «Какой будет следующая Opus от Anthropic?»

Анжела, привет. Готов цикл из 4 материалов про новую модель Anthropic — Claude Mythos — и стратегию её закрытого preview через Project Glasswing. Mozilla прогнали Mythos по Firefox 150 и за апрель получили 271 уязвимость безопасности, включая 15-летний баг в `<legend>` и 20-летний в XSLT. Главный угол цикла: Anthropic первыми в индустрии явно тормозят публичный релиз топ-модели ради safeguards и обещают дать Mythos-class способности в будущей публичной Opus.

Если что-то непонятно — пиши, разберёмся.

---

## Что публикуем

Тема: разбор стратегии Anthropic — топ-модель Claude Mythos в публичный API не выпускают, она работает только в Project Glasswing с Apple, AWS, Google, Microsoft и ещё горсткой гигантов. Mozilla — единственная пока публично отчитавшаяся, и её кейс показывает, ради чего вся эта закрытость: 271 уязвимость в Firefox 150 за месяц, включая 15- и 20-летние «древности».

**4 материала:**

1. **Habr** — основная статья (~7 600 знаков, технический разбор кейса + стратегии Anthropic)
2. **TenChat** — деловая версия (~5 800 знаков, для руководителей: что значит «эксклюзивщина для консорциума» и как готовиться к публичной Opus с Mythos-class способностями)
3. **Pikabu** — народная версия (~10 200 знаков, на «ты», с поворотом «ору от цифр, но Mythos нам не дадут»)
4. **Telegram-анонс** — анонс Habr-статьи (3 варианта в файле, рекомендуемый — Вариант 1)

Все файлы — в свежем коммите, после `git pull` будут у тебя.

## Особенности именно этого цикла

**Главный угол — стратегия Anthropic, а не сам кейс.** В статьях явно сказано, что Mythos в публичный API НЕ выйдет, и автор ждёт следующую публичную Opus с Mythos-class способностями (когда Anthropic доделают safeguards). Не правь формулировки «жду следующую Opus», «не получим Mythos», «когда Anthropic откроют способности» — это центральный тезис цикла.

**Совместный анонс Mozilla × Anthropic.** В статьях отмечено, что обе стороны заинтересованы в позитивной презентации, и я к цифрам отношусь с прищуром. Это часть позиции — не смягчай и не убирай, иначе Habr-аудитория поймает на «AI-CEO евангелизме».

**Project Glasswing — реальный список участников.** Apple, AWS, Google, Microsoft, Cisco, CrowdStrike, JPMorgan Chase, Linux Foundation, NVIDIA, Palo Alto Networks, Broadcom + сама Anthropic. Это публичная информация ([anthropic.com/glasswing](https://www.anthropic.com/glasswing)), список не выдумка. Если в редакторе кого-то подсветит как «непроверяемое» — направь на эту ссылку.

**Дата анонса Mythos** — 7 апреля 2026 ([red.anthropic.com/2026/mythos-preview/](https://red.anthropic.com/2026/mythos-preview/)). Не путать с датой статьи Mozilla (май). Если в тексте всплывёт «недавно» — оставь, обе даты совместимы.
