# Telegram: Анонс статьи про Mythos и следующую Opus от Anthropic на Хабре

## Вариант 1: Контраст «не дают / уже работает» (рекомендуемый)

📌 **Anthropic не выпустят Claude Mythos в API. Mozilla уже работает с ней через Project Glasswing — 271 уязвимость в Firefox за апрель.**

Anthropic 7 апреля анонсировали Mythos Preview — модель, которая автономно находит уязвимости в крупных кодбейзах. И сразу заявили: публично её не отдадим. Доступ — только Apple, AWS, Google, Microsoft, Cisco, NVIDIA, Linux Foundation и ещё горстке гигантов через Project Glasswing. Mozilla туда же — и за апрель из Firefox 150 они вытащили 271 баг безопасности, включая 15-летний в `<legend>` и 20-летний в XSLT.

В статье разобрал:
• Почему Anthropic тормозят релиз — и что это меняет для всей индустрии
• Какой будет следующая публичная Opus, в которой обещают открыть Mythos-class способности
• Чем мой `bug-hunter` сегодня отличается от того, что делает Mythos на проде Firefox
• Почему 271 найденный баг не отменяет security-инженеров, а делает их ценнее

Это первый раз, когда топ-лаба явно говорит «не сейчас, нам нужны safeguards». Кейс Mozilla показывает, почему.

## Вариант 2: Личное ожидание новой Opus

📌 **Anthropic не дают новую модель в API. Я жду следующую Opus — в которой обещают открыть способности Mythos под safeguards.**

Mozilla уже получили доступ к Mythos через закрытый консорциум Project Glasswing и за апрель вытащили из Firefox 150 целых 271 баг — включая 15- и 20-летние «древности» в `<legend>` и XSLT. Я смотрю на этот кейс глазами того, кто ведёт open-source kit с собственным `bug-hunter` и хочет получить такую же модель в API.

В статье разобрал:
• Что Anthropic сказали про сроки публичной Opus с Mythos-class способностями (спойлер: ничего конкретного, но обещание есть)
• Какие классы багов нашёл Mythos у Mozilla — и какую лигу сложности это меняет
• Что я хочу проверить на своих коммерческих проектах, когда Opus с этими способностями выйдет
• Где Anthropic недоговорили в отчёте — false positive рейт, воспроизводимость

Если ваш кодбейз публичный — давайте попробуем вместе, как только новая Opus станет доступна.

## Вариант 3: Стратегический сдвиг лабы

📌 **Anthropic первыми в индустрии явно тормозят публичный релиз топ-модели ради safeguards. Кейс Mozilla показывает, что именно они задерживают.**

Claude Mythos Preview анонсирована 7 апреля. Mozilla за апрель прогнала её по Firefox 150 — 271 уязвимость, 180 sec-high, sandbox escape, race conditions через IPC, обходы RLBox. Среди находок — баги, которые сидели в коде по 15 и 20 лет.

И эту модель Anthropic в публичный API **не выпускают**. Доступ — только Apple, Google, Microsoft, AWS и ещё горстка через Project Glasswing. Публикa получит Mythos-class способности в будущей Opus, когда лаба доделает safeguards.

Что это значит:
• Топ-лабы перестают выкатывать модели в API «как только»
• Окно эксклюзивного преимущества по applied security — у консорциума гигантов
• Малому и среднему бизнесу нужно стратегически закладывать этот разрыв
• Когда Opus с Mythos-class способностями выйдет — окно закроется, но подготовка кодбейза стоит начать сейчас

В статье — разбор кейса Mozilla, стратегии Anthropic и практические выводы для тех, кто принимает решения про security-бюджет.
