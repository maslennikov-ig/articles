# 83 способа бесплатно использовать AI-агента, который работает пока ты спишь

> **TL;DR**: Moltbot — **полностью бесплатный** AI-агент с открытым кодом (100K+ звёзд на GitHub, MIT лицензия). Работает 24/7 на твоём компе, управляется через Telegram. Это не ChatGPT — он реально нажимает кнопки, заказывает еду, торгуется за машину, отвечает на почту. 83+ готовых сценария. Единственный расход — API ($25-150/мес), но можно и бесплатно через локальные модели.

Длиннопост. Знаю, минусы прилетят за "очередной хайп про AI", но всё равно расскажу.

Наткнулся на проект с 100K+ звёзд на GitHub — один из самых быстрорастущих open-source за всю историю. Сначала думал "ну ещё один чат-бот". А потом посмотрел, что люди реально делают — и офигел.

Это не ChatGPT. Это **агент**. Разница в том, что ChatGPT отвечает текстом, а этот — реально делает: открывает браузер, кликает кнопки, отправляет письма, заказывает еду. Пока ты спишь.

Собрал 83+ способа использования из видео автора, Reddit, GitHub и добавил свои. **Адаптировал под российские реалии** — Wildberries вместо Amazon, Яндекс.Еда вместо UberEats, российские банки и сервисы.

## 💰 Почему это бесплатно?

Сразу отвечу на главный вопрос: "В чём подвох?"

**Сам бот — полностью бесплатный:**
* MIT лицензия — бери и пользуйся
* Открытый код на GitHub — можешь сам проверить
* 700+ готовых скиллов — тоже бесплатно
* Никаких подписок, никаких "премиум-версий"

**Единственный расход — API для "мозгов":**

Бот — это оболочка. Мозги (AI) он берёт у Anthropic или OpenAI. Это как телефон: аппарат твой, а за связь платишь оператору.

* Лёгкое использование (напоминалки, календарь): ~$25/мес
* Среднее (почта, рисёрч, автоматизация): ~$50-80/мес
* Активное (кодинг, многоагентность): ~$100-150/мес

Для сравнения: личный ассистент стоит от 50,000₽/мес. А тут — $50 за робота, который работает 24/7.

**Альтернатива — бесплатные локальные модели:**

Можно использовать Ollama с локальными LLM (Llama, Mistral). Тогда вообще 0₽. Но качество хуже — для простых задач пойдёт, для сложных нет.

## 🏠 Личная эффективность и быт (17 способов)

**1. Утренний брифинг**

Бот собирает погоду (Яндекс.Погода), задачи из Todoist, встречи из Google Calendar, новости из твоих Telegram-каналов. Генерирует сводку и присылает голосовым или текстом в 7:00. "Сегодня -5, три встречи, вечером футбол в 21:00, в Ленте скидка на кофе".

**2. Заказ завтрака**

Бот подключён к Яндекс.Еде или Самокату. Когда ты пишешь "Доброе утро" (или он видит, что ты проснулся по трекеру сна), он заказывает твой стандартный завтрак. К моменту выхода из душа — еда у двери.

**3. Умная сортировка почты**

Бот читает Gmail через API. Рассылки и спам — в архив. Важные письма помечает флагом. На письма типа "Когда будет готов отчёт?" — готовит черновик ответа. Тебе остаётся только нажать "Отправить".

**4. Напоминания естественным языком**

"Напомни купить молоко вечером". Бот понимает и ставит напоминание в Apple Reminders или Google Tasks. Не нужно открывать приложение, выбирать дату, время.

**5. Голосовые заметки за рулём**

Ты едешь и наговариваешь мысли голосовухой в Telegram. Бот транскрибирует, выделяет задачи, сохраняет в Notion: "Идеи: 1. Позвонить Васе 2. Купить резину 3. Дописать презентацию".

**6. Личная база знаний ("Второй мозг")**

Все твои заметки, документы, чаты индексируются. Спрашиваешь: "О чём мы договорились с тем клиентом полгода назад?" — бот находит ответ, даже если ты забыл где это записано.

**7. Умный календарь**

Кто-то хочет встречу. Пересылаешь контакт боту. Он сам пишет человеку: "Вот свободные слоты, выберите время". После выбора создаёт событие в календаре и присылает ссылку на Zoom.

**8. Разделение счетов после посиделок**

После бара или поездки скидываешь фото чека. "Нас было пятеро, платил я". Бот считает кто кому сколько должен и может отправить запрос друзьям в Telegram.

**9. Управление подписками**

Бот сканирует почту за год на предмет чеков от сервисов (Яндекс.Плюс, VK Музыка, Netflix). Присылает отчёт: "За год ты потратил на подписки 47,000₽. Вот что можно отменить".

**10. Трекинг здоровья**

Подключается к Apple Health или Mi Fit. "Как мой пульс на этой неделе по сравнению с прошлой?" — строит график, даёт анализ.

**11. Автоматический Kanban**

Бот анализирует переписку с ним. Обсуждаете новую идею — сам создаёт карточку в Trello "To Do". Выполнил задачу — сам двигает в "Done". Не нужно вручную.

**12. Проверка умного дома**

"Я закрыл входную дверь?" — бот опрашивает датчики Home Assistant и отвечает. Важно: автор советует не давать право открывать, только проверять статус.

**13. Имитация присутствия (режим отпуска)**

Когда уезжаешь в отпуск, бот в случайном порядке включает/выключает свет в разных комнатах и музыку по вечерам. Создаёт иллюзию, что дома кто-то есть.

**14. Адаптивный климат**

Если есть датчик CO2, бот мониторит уровень. Стало душно — сам включает умную розетку с вентилятором или приточным клапаном.

**15. Фото-отчёт с камер**

"Покажи, кто у двери" — бот делает снапшот с камеры и присылает картинку в Telegram.

**16. Управление музыкой**

"Включи музыку для фокуса" — бот запускает плейлист в Spotify на компе без переключения окон.

**17. Анимированное лицо (Digital Presence)**

На отдельном экране или планшете отображается аватар. Когда бот "думает" — меняет выражение. Эффект присутствия помощника в комнате. Да, это понты, но прикольно.

**19. Мониторинг статуса рейса**

Подключается к API авиалиний. Если задержка — сразу пишет: "Рейс SU123 задержан на 2 часа". Не нужно мониторить самому.

**20. Управление Tesla через API**

За 10 минут до выхода бот включает кондиционер/обогрев в машине. Или проверяет уровень заряда. Работает с любым авто с API (также китайские электрокары).

**21. Поиск мест (Google Places)**

"Найди кофейню с WiFi рядом" — бот выдаёт рейтинг, часы работы, расстояние. Для России работает через Яндекс.Карты API.

**22. Бронирование ресторанов**

"Итальянский ресторан на пятницу вечер, 4 человека" — бот ищет свободные слоты на afisha.ru или localway, если нет мест — мониторит отмены.

"Купи ещё зубной пасты" — бот ищет твой привычный бренд, кладёт в корзину, оформляет заказ. Нужна настройка авторизации, но работает.

**25. Karen Skill (Профессиональный жалобщик)**

Пользователю отказали в выплате страховки. Он загрузил боту PDF со страховкой и счёт из больницы. Бот проанализировал документы, нашёл пункт доказывающий правоту, написал официальную апелляцию. Страховку выплатили.

Фотографируешь чек, отправляешь боту. Он распознаёт сумму, категорию, добавляет в Google Таблицу "Бюджет". Не нужно вручную вбивать.

**29. Налоговый помощник для ИП/самозанятых**

Если бот имеет доступ к выписке (через банковский API или CSV), он категоризирует траты: "Это бизнес-расход", "Это личное". Упрощает подачу декларации.

**30. Мониторинг крипто-портфеля**

Проверяет балансы кошельков/бирж, присылает общую стоимость активов. "Твой портфель: $X (+5% за неделю)".

**31. Мониторинг новых токенов**

Следит за новыми листингами криптовалют на DEX. Присылает алерт: "Новый токен XYZ на Uniswap, объём $1M за час".

**32. Платежи через MoonPay**

Интеграция для быстрой покупки крипты (если настроено). Пишешь "Купи ETH на $100" — бот делает.

**33. Трейдинг (осторожно!)**

**34. Календарь событий с афиш**

## 📹 Создание контента и соцсети (10 способов)

**35. Анализ конкурентов на YouTube**

Бот сканирует каналы конкурентов, ищет "аномалии" — видео, которые набрали значительно больше просмотров чем среднее. Присылает отчёт: "Вот тема, которая сейчас в тренде — сними такое".

**36. Генерация видео (Remotion)**

Бот парсит новости → пишет сценарий → использует библиотеку Remotion для анимации текста и картинок → рендерит готовый MP4. Полностью автоматические новостные сводки.

**37. Создание Shorts/Reels**

Нарезает длинные видео на короткие клипы. LLM находит самые интересные моменты, FFmpeg вырезает, добавляет вертикальный формат 9:16 и субтитры. Аналог Opus Clip, но бесплатно.

**38. Инфографика из набросков**

Рисуешь схему на салфетке, фотографируешь. Бот распознаёт структуру и генерирует чистую инфографику в SVG или HTML/CSS.

**39. Ответы в Twitter/X**

Бот мониторит посты лидеров мнений в твоей нише. Как только выходит пост — генерирует осмысленный комментарий (не "Great post!", а с контекстом) и публикует. Привлекает внимание к твоему профилю.

**40. Очистка спама в директе**

Читает запросы на переписку. "Купи крипту", "Привет, красотка" — удаляет/блокирует. Реальные предложения — пропускает.

**41. Дайджест закладок**

Многие сохраняют твиты и забывают. Раз в неделю бот проходит по новым закладкам, делает выжимку: "Вот что полезного ты сохранил".

**42. Генерация изображений**

Прямо в чате: "Нарисуй кота в стиле киберпанк" — бот передаёт промпт в DALL-E/Midjourney и возвращает картинку. Не нужно открывать Discord.

**43. Имитация в чатах (осторожно!)**

Бот может отвечать от твоего имени в групповых чатах. Например, в рабочем чате писать "Ок, сделаю" пока ты занят. Использовать осторожно.

**44. Мониторинг бренда**

Поиск по ключевым словам (твоё имя, название компании) в VK, Telegram, новостях. При упоминании — алерт со ссылкой и тональностью (позитив/негатив).

## 💼 Бизнес и работа (10 способов)

Ты настраиваешь такого бота не для себя, а для стоматологии или салона красоты. Он записывает клиентов, отвечает на вопросы. Продаёшь это как услугу за 15-30К/мес.

**46. Управление малым бизнесом**

Реальный кейс: чайный магазин родителей автора. Бот отслеживает остатки (нужно дозаказать?), составляет графики смен сотрудников, автоматически отвечает на типовые вопросы в поддержке.

**47. Глубокий рисёрч (Deep Research)**

"Узнай всё о рынке кофе в России". Бот заходит в Google, читает 30 статей, PDF-отчётов, выделяет факты и цифры, собирает в один документ с источниками. За ночь.

**48. Генерация резюме под вакансию**

Даёшь боту своё полное резюме и текст вакансии. Он переписывает CV так, чтобы выделить именно тот опыт, который нужен работодателю. Ключевые слова для прохождения ATS-фильтров.

**49. Конвертация файлов**

"Переведи эту презентацию в PDF", "Сожми видео до 50МБ", "Конвертируй DOCX в Markdown". Бот делает через ffmpeg и pandoc.

**50. Оцифровка встреч**

После совещания фоткаешь белую доску. Бот превращает рукописный текст и схемы в документ Notion с пунктами действий (Action Items).

**51. Создание PRD (техзадания)**

Надиктовываешь сумбурные мысли голосовым. Бот структурирует в профессиональный Product Requirements Document: цели, User Stories, технические ограничения.

**52. SQL-помощник**

"Напиши запрос — топ-10 пользователей по тратам за прошлый месяц из таблицы orders". Бот может (при наличии доступа) сам выполнить запрос к базе и вернуть CSV.

**53. Перевод документации**

Скачивает README библиотеки, переводит на русский сохраняя Markdown-форматирование, сохраняет локально.

**54. Автоматическое Code Review**

"Посмотри мой последний Pull Request, есть ли ошибки?". Бот анализирует диффы кода, находит баги и неоптимизированные места.

## 💻 Программирование (9 способов)

**55. Партнер по кодингу (Rubber Ducking)**

Бот имеет доступ к твоему репозиторию. Спрашиваешь: "Как лучше реализовать эту функцию?" — он видит контекст всего проекта и даёт совет, учитывая существующий код.

**56. QA Тестирование**

Бот пишет и запускает сценарии через Playwright. "Ходит" по сайту, кликает кнопки. Если ошибка 500 или кнопка не сработала — делает скриншот, сохраняет лог, присылает баг-репорт.

**57. Многоагентная разработка**

Один агент пишет бэкенд, другой фронтенд, третий делает код-ревью. Обмениваются данными и коммитят в общий репозиторий. Симуляция команды.

**58. Параллельная разработка**

Написание кода сразу для нескольких проектов одновременно — пока ты спишь.

**59. Production баги до прихода команды (реальный кейс)**

Разработчик настроил бота мониторить логи. Ночью падал продакшен — бот находил ошибку, писал фикс, создавал PR. Утром команда видела готовый фикс для ревью.

**60. Git-менеджер**

"Создай ветку feature/login, закоммить все изменения с сообщением 'wip' и отправь на сервер". Одной командой.

**61. GitHub Issues**

Если бот находит баг или ты просишь добавить фичу — сам создаёт Issue в репозитории на GitHub с описанием.

**62. Управление базами данных**

Интеграция с Supabase/Firebase. "Покажи последние 100 юзеров" — бот выполняет и возвращает данные.

**63. Аудит зависимостей**

Периодически проверяет библиотеки проекта (npm audit, pip check). Присылает: "В библиотеке X найдена критическая уязвимость, вышла версия с исправлением. Обновить?"

## 🛡️ Безопасность (4 способа)

**64. Сканирование секретов**

Перед отправкой кода на GitHub бот сканирует файлы на наличие забытых паролей/API-ключей. Если находит — блокирует отправку.

**65. Мониторинг цифрового следа**

Раз в неделю гуглит твой никнейм или почту, проверяет HaveIBeenPwned. Если данные утекли — присылает алерт.

**66. Проверка лендингов**

Каждые 2 часа пингует сайты. Если упал — сразу уведомление. Не нужен отдельный uptime-сервис.

**67. Анализ CTR**

Выявляет рекламные объявления, на которые перестали кликать (выгорание аудитории). Рекомендует обновить креативы.

## 🛠 Как установить (пошагово для чайников)

Да, это не "нажми кнопку и работает". Но если ты хоть раз ставил программы через терминал — справишься за 15-30 минут.

**Что нужно заранее:**

* **API ключ** — Anthropic (console.anthropic.com) или OpenAI. Нужна зарубежная карта. Если нет — гугли "как оплатить Anthropic из России", есть способы
* **Telegram бот** — создаётся за минуту через @BotFather (пишешь /newbot, получаешь токен)
* **Node.js 22+** — скачиваешь с nodejs.org, ставишь как обычную программу

---

**Вариант 1: Локально (бот работает пока комп включён)**

Подходит для тестов. Бесплатно (кроме API).

Открываешь терминал (на Mac: Terminal, на Windows: PowerShell), пишешь:

npm install -g moltbot@latest

moltbot onboard --install-daemon

Дальше интерактивный мастер: вводишь API ключ, Telegram токен, выбираешь каналы связи. Готово.

Идёшь в Telegram, находишь своего бота, пишешь "Привет". Если ответил — работает.

---

**Вариант 2: На сервере (бот работает 24/7)**

Подходит если хочешь чтобы бот работал пока ты спишь. Стоит 200-500₽/мес за VPS.

**Шаг 1. Арендуй сервер**

Любой российский хостинг: Timeweb, Aeza, Selectel. Выбираешь:
* OS: Ubuntu 22.04 или 24.04
* Тариф: самый дешёвый (1-2 ядра, 2GB RAM хватит)

На почту придёт IP-адрес и пароль.

**Шаг 2. Подключись к серверу**

В терминале пишешь:

ssh root@твой-ip-адрес

Спросит пароль. Когда вводишь — символы не отображаются (это нормально, защита от подглядывания). Просто вводи и жми Enter.

**Шаг 3. Установи Node.js**

Копируй и вставляй команды по очереди:

apt update && apt upgrade -y

curl -fsSL https://deb.nodesource.com/setup_22.x | bash -

apt install -y nodejs

Проверь что установилось: node -v (должно показать v22.x.x)

**Шаг 4. Установи бота**

npm install -g moltbot@latest

moltbot onboard --install-daemon

Вводишь свои ключи как в локальной версии.

**Шаг 5. Сделай чтобы бот работал вечно**

По умолчанию если закроешь терминал — бот выключится. Нужна программа PM2:

npm install -g pm2

pm2 start moltbot --name "moltbot"

pm2 save

pm2 startup

Теперь бот работает 24/7. Даже после перезагрузки сервера сам включится.

---

**Частые проблемы:**

* "Command not found: npm" — не установил Node.js
* Бот не отвечает — проверь баланс на Anthropic (если 0 — не работает)
* Как обновить? — ssh на сервер, потом: npm update -g moltbot && pm2 restart moltbot
