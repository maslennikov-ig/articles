# Не все AI-модели одинаково полезны: тестирование 11 LLM для образовательного контента

## Не все AI одинаковы для образования

Когда мы запускали автоматизацию генерации учебных курсов, первый вопрос был простой: **какую модель использовать?** GPT-4? Claude? Может, что-то дешевле?

Вместо того чтобы гадать, мы провели полноценное исследование: **11 LLM-моделей, 120+ реальных API-вызовов, 4 сценария тестирования** (английские/русские метаданные курсов, английские/русские уроки). Результат удивил: **самая дорогая модель не всегда лучший выбор**, а стратегический микс моделей дает 94% качества премиум-уровня при 27% стоимости.

Вот что мы выяснили за несколько месяцев тестирования на реальных образовательных курсах.

---

## Кто я и зачем это тестировал

**Игорь Масленников**, в IT с 2013 года. Последние два года руковожу AI Dev Team в компании DNA IT. Мы автоматизировали генерацию учебных курсов для EdTech-проектов: клиенты загружают названия курсов или сырые материалы, система генерирует структурированные образовательные программы с метаданными, уроками, упражнениями.

**Проблема**: Разные LLM-модели дают разное качество педагогического контента. Какую выбрать? Дорогую (но может быть избыточную)? Дешевую (но рискуя качеством обучения)? А может, миксовать модели под задачи?

**Решение**: Провести количественное сравнение 11 моделей на реальных задачах, измерить качество через семантическое сходство с эталонами (Jina-v3 embeddings), посчитать cost-quality frontier, выработать стратегию выбора.

### Сценарии тестирования

**4 категории контента**:
1. **Metadata EN** (английские метаданные): Course overview, learning outcomes, prerequisites, module structure
2. **Metadata RU** (русские метаданные): Описание курса, результаты обучения, требования, структура модулей
3. **Lessons EN** (английские уроки): Lesson content, exercises, technical depth, code examples
4. **Lessons RU** (русские уроки): Контент урока, упражнения, технические формулы, примеры кода

**Критерии качества**:
- **Bloom's verbs usage**: Использование глаголов таксономии Блума (analyze, evaluate, create vs. remember, understand)
- **Exercises per lesson**: Количество упражнений (2+ = глубина проработки)
- **Technical depth**: Формулы, код, граничные случаи (например, vanishing gradients в нейросетях)
- **Pedagogical soundness**: Логичная прогрессия от простого к сложному

**Метод измерения**: Jina-v3 semantic similarity (768-размерные эмбеддинги, late chunking) — сравнение сгенерированного контента с эталонными образовательными материалами.

## Пример сравнения качества

Давайте сравним, как две модели генерируют урок **"Understanding Neural Network Backpropagation"**.

### Kimi K2 Thinking (10/10 Lessons EN, $2.63)

```

Content:
- 2 упражнения на урок
- Математические формулы: ∂E/∂w = ∂E/∂y × ∂y/∂w (chain rule)
- Граничные случаи: vanishing gradients (sigmoid), exploding gradients (ReLU without normalization)
- Примеры кода: numpy implementation с real datasets
- Стоимость: $0.0053 за урок

### Qwen3 235B Thinking (8/10 Lessons EN, $0.70)

```

## Дерево принятия решений: Какую модель выбрать?

```
СТАРТ: Новый запрос на генерацию курса

IF язык_курса == "английский" AND тип_контента == "метаданные":
  → Grok 4 Fast (10/10 качество, $0.96)

ELSE IF язык_курса == "русский" AND тип_контента == "уроки" AND категория == "техническая":
  → MiniMax M2 (10/10 русский технический контент, $1.37)

ELSE IF премиум_тир OR сертификационный_курс OR compliance_critical:
  → Kimi K2 Thinking (9.6/10 средний балл, универсальное превосходство)

ELSE:
  → Qwen3 235B Thinking (8.6/10 качество, $0.70, лучшее соотношение)
```

**Практика**: На основе метаданных курса (язык, категория, приоритет) система автоматически выбирает модель. Никаких manual overrides — логика закодирована в decision tree.

### Урок 1: Самая дорогая модель ≠ лучшее качество

**Для 70% сценариев** (стандартные курсы) эта разница не оправдывает 3.75x увеличение стоимости.

### Урок 2: Специализация имеет значение

Grok 4 Fast — идеален для английских метаданных (10/10). MiniMax M2 — идеален для русских технических уроков (10/10).

**Используйте правильный инструмент для правильной задачи**, а не universal model для всего.

---

### Урок 3: Фокусируйтесь на качество/$, а не на абсолютное качество

8.6/10 за $0.70 (12.3 качество/$) **лучше**, чем 9.6/10 за $2.63 (3.7 качество/$) — если вам не нужна критическая разница в качестве.

**ROI-подход**: Для EdTech-платформ важнее снизить cost per course, сохраняя приемлемое качество (8+/10).

### Урок 4: Контекстное окно влияет на use cases

## Ключевые выводы

1. **Не все LLM одинаковы для образования**: Протестируйте модели на ваших реальных сценариях (метаданные, уроки, язык, техническая глубина).

2. **Стратегический микс > одна модель**: 70% Qwen3 + 15% Kimi K2 + 10% Grok 4 + 5% MiniMax = 93.8% качества при 13.3% стоимости.

3. **Фокус на качество/$, а не абсолютное качество**: 8.6/10 за $0.70 лучше, чем 9.6/10 за $2.63 для большинства сценариев.

4. **Специализация имеет значение**: Используйте Grok 4 для английских метаданных, MiniMax M2 для русского технического контента.

5. **Измеряйте, а не гадайте**: Jina-v3 semantic similarity, 120+ API calls, cost-quality frontier — только так можно принять обоснованное решение.
