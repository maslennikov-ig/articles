# Как я нашёл бесплатного AI-дизайнера, который ищет клиентов и рисует за меня (MIT лицензия, никаких подписок)

## Привет, Пикабу!

Меня зовут Игорь, в IT с 2013 года. Последние 2 года занимаюсь AI-инструментами. И сегодня расскажу про штуку, которая превратила мой Claude Code из "умного редактора кода" в комбайн, который генерирует арт, ищет клиентов и создаёт дизайн — причём абсолютно бесплатно.

**Не верите?** Сейчас покажу.

## Проблема: хочу зарабатывать на дизайне, но я не дизайнер

Ситуация знакомая: есть идея, нужна обложка для статьи, постер для мероприятия, генеративный арт для NFT (да-да, или просто для души). Варианты:

1. **Нанять дизайнера** — от 5000₽ за постер, от 10000₽ за серию артов.
2. **Учиться самому** — 3-6 месяцев на Illustrator/Figma, не факт что получится красиво.
3. **Использовать шаблоны** — выглядит как шаблон, все такие.

А если ты фрилансер и хочешь найти клиентов? Ещё одна проблема:

4. **Лид-генерация** — сервисы типа Hunter.io стоят от $50/месяц, надо вручную искать контакты.

Я нашёл 4-й путь: **запустить AI-скиллы, которые делают всё это бесплатно**.

## Что за скиллы? (Спойлер: это не SaaS, не подписка)

В моём проекте [claude-code-orchestrator-kit](https://github.com/maslennikov-ig/claude-code-orchestrator-kit) (MIT лицензия, открытый код) есть набор AI-скиллов — специализированных агентов, которые делают конкретные задачи.

Из 33+ агентов я выделю **5 творческих**, которые интересны фрилансерам, блогерам, креативщикам:

### 1. **algorithmic-art** — генеративный арт через p5.js

**Что делает:**
Создаёт уникальные алгоритмические артворки (flow fields, particle systems, fractals). Ты задаёшь философию арта текстом, AI пишет код на p5.js, генерирует HTML-артефакт, который можно открыть в браузере.

**Фишка:** Seeded randomness (как в Art Blocks) — один seed даёт одну уникальную картинку, меняешь seed — получаешь новый арт.

**Пример запроса:**
```
Создай генеративный арт: ocean waves meeting desert dunes,
minimalist color palette (blues + golds),
particle flow field simulation.
```

AI генерирует интерактивный HTML с p5.js кодом. Открываешь в браузере — получаешь живой арт, который можно:
- Экспортировать в PNG/SVG
- Менять seed для новых вариаций
- Продавать на Etsy/Redbubble
- Использовать для обложек статей/YouTube

**Замена:** Художник-абстракционист (от 10000₽ за работу) или Midjourney Pro ($30/месяц).

---

### 2. **canvas-design** — постеры, обложки, инфографика

**Что делает:**
Создаёт визуальный дизайн (.png, .pdf) через design philosophy. Ты описываешь концепцию, AI создаёт композицию с типографикой, цветами, элементами.

**Пример запроса:**
```
Создай постер для мероприятия:
Тема: "Нейросети для фрилансеров"
Стиль: brutalist design, чёрно-белый + один акцентный цвет (оранжевый)
Типографика: крупный заголовок, дата внизу
Формат: A3, PDF для печати
```

AI создаёт дизайн-философию (композиция, шрифты, пропорции), затем генерирует canvas в .png или многостраничный .pdf.

**Что можно делать:**
- Обложки для статей (Medium, VC.ru, Habr)
- Постеры для мероприятий
- Инфографика для презентаций
- Визитки, флаеры

**Замена:** Дизайнер на Kwork (от 3000₽ за постер) или Canva Pro ($13/месяц, но там шаблоны).

---

### 3. **theme-factory** — 10 готовых тем для всего

**Что делает:**
Применяет готовые темы к артефактам: презентациям, лендингам, документам. 10 премейд-тем с сочетаниями цветов/шрифтов (minimal, brutalist, neon, retro и т.д.).

**Пример запроса:**
```
Примени тему "neon" к моей презентации (slides.html).
```

AI применяет тёмный фон, неоновые акценты (cyan, magenta), monospace шрифты. Готово.

**Что экономишь:** Время на подбор цветовой палитры (1-2 часа) или покупку темы PowerPoint ($20-50).

---

### 4. **lead-research-assistant** — AI ищет клиентов за тебя

**А вот это для заработка.**

**Что делает:**
Анализирует твой продукт/услугу, ищет целевые компании через веб-поиск, предоставляет стратегии контакта.

**Пример запроса:**
```
Найди лиды для моего продукта:
Услуга: дизайн логотипов для стартапов
Целевая аудитория: IT-стартапы на pre-seed, Россия/СНГ
Бюджет: до 50000₽ за логотип
```

AI делает:
1. **Анализ бизнеса** — определяет идеальный профиль клиента (ICP)
2. **Поиск компаний** — через WebSearch ищет подходящие стартапы, проверяет их сайты
3. **Стратегия контакта** — предлагает, как выйти на них (LinkedIn, email, Telegram)

**Результат:** 10-20 тёплых лидов с описанием, контактами, рекомендациями по outreach.

**Замена:** Hunter.io ($50/мес), LinkedIn Sales Navigator ($80/мес), или ручной поиск (10 часов работы).

---

### 5. **content-research-writer** — помощь в написании статей

**Что делает:**
Помогает писать статьи с research и цитатами. Collaborative outlining (совместное создание структуры), поиск источников, улучшение hook'ов, feedback по секциям.

**Пример запроса:**
```
Помоги написать статью:
Тема: "Как использовать AI для поиска клиентов на фрилансе"
Цель: привлечь подписчиков на Telegram-канал
Длина: 2000-3000 слов
```

AI:
1. Создаёт outline (план статьи) — предлагает структуру разделов
2. Ищет источники — находит статистику, кейсы, цитаты
3. Пишет hook (зацепку) — делает первый абзац цепляющим
4. Даёт feedback по секциям — комментирует каждый раздел

**Что экономишь:** Копирайтер (от 2000₽/1000 знаков) или 5-10 часов самостоятельной работы.

## Сколько можно сэкономить/заработать?

Посчитаем на примере **фрилансера-дизайнера**:

* **Canva Pro** — $13/мес → замена: `canvas-design` (бесплатно)

* **Дизайнер** (разовая работа) — 10000₽ → замена: `canvas-design` (бесплатно)
* **Копирайтер** (статья) — 5000₽ → замена: `content-research-writer` (бесплатно)

**Экономия:** ~$100/месяц (~9000₽) + разовые работы 15000₽.

### Заработок на фрилансе:

Пример портфолио за неделю (используя AI-скиллы):

1. **Генеративный арт** (algorithmic-art): 5 уникальных работ для продажи на Etsy → 3000₽
2. **Постеры для мероприятий** (canvas-design): 3 постера для клиентов → 9000₽
3. **Лид-генерация** (lead-research-assistant): нашёл 20 лидов, 2 конвертировались → 50000₽ (2 логотипа по 25000₽)

**Итого за неделю:** 62000₽.

**Реально ли?** Да, если у тебя уже есть навыки презентации работ и outreach. AI не заменяет продажи, но **устраняет затраты на дизайн и research**.

## Как это работает технически? (Без боли)

### Установка (5 минут):

```bash
# 1. Установить пакет
npm install -g claude-code-orchestrator-kit

# 2. Настроить Claude Code (если ещё не настроен)
# Следуй инструкциям в README: https://github.com/maslennikov-ig/claude-code-orchestrator-kit

# 3. Готово!
```

### Использование:

Открываешь Claude Code (через официальное приложение или CLI), пишешь запрос:

```
Используй скилл algorithmic-art:
Создай генеративный арт: cosmic nebula with flowing particles,
color palette: purples and teals, interactive controls for density.
```

Claude Code:
1. Вызывает скилл `algorithmic-art`
2. Генерирует p5.js код
3. Создаёт HTML-файл
4. Сохраняет в папку проекта

Открываешь HTML в браузере — получаешь интерактивный арт. Меняешь параметры (seed, density) прямо в браузере.

**Никаких API ключей, никаких подписок** (кроме самого Claude Code, который у тебя уже есть).

## Disclaimer: Expected Pushback

Понимаю, что эта статья вызовет вопросы (или возмущение) у профессиональных дизайнеров и художников.

**Типичные реакции:**
- "AI не заменит настоящего художника!"
- "Это халтура, не искусство!"
- "Лид-генерация — это спам!"

**Моя позиция:**

**Про AI и художников:**
Да, AI не заменит художника с авторским стилем и глубоким пониманием композиции. Но 80% коммерческих задач — это постеры для мероприятий, обложки для статей, простые логотипы. Раньше за это платили 5000-10000₽ дизайнеру, теперь можно сделать самому за 15 минут.

**AI не убивает профессионалов** — он убирает рутину. Художники теперь могут фокусироваться на сложных проектах (брендинг, иллюстрации для книг, концепт-арт), а не на шаблонных заказах.

**Про лид-генерацию:**
Да, если писать всем подряд "Купите мой продукт!" — это спам. Но `lead-research-assistant` **не рассылает письма автоматически**. Он только находит подходящие компании и предлагает стратегию. Ты сам решаешь, как и кому писать.

**Разница между спамом и outreach:**
- **Спам:** 1000 одинаковых писем всем подряд
- **Outreach:** 10 персонализированных сообщений компаниям, которым реально подходит твой продукт

AI помогает со вторым.

**Если не согласен** — окей. Попробуй скиллы, посмотри на результат, потом критикуй. Технические аргументы приветствуются.
