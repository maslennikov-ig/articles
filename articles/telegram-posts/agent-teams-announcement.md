# Agent Teams в Claude Code: когда одного агента недостаточно

Anthropic добавила экспериментальную функцию **Agent Teams** — возможность координировать команду из нескольких Claude, работающих вместе.

## В чём фишка?

В отличие от subagents (которые только отчитываются главному), teammates:
- Общаются между собой напрямую
- Ведут дебаты и приходят к консенсусу
- Координируются через общий task list
- Работают в независимых контекстах

## Когда это полезно?

**1. Параллельный code review**
3 ревьюера одновременно: security, performance, tests. Находят больше проблем.

**2. Отладка с конкурирующими гипотезами**
5 агентов тестируют разные теории, спорят и опровергают друг друга. Побеждает та, что выживает.

**3. Разработка новых модулей**
Каждый teammate владеет своей частью — нет конфликтов.

## Архитектура

```
Team Lead → координирует
  ├─ Security Reviewer
  ├─ Performance Checker
  └─ Test Validator
     ↓
Общий Task List + Mailbox
```

## Ограничения

- Экспериментальная функция (выключена по умолчанию)
- Жрёт токены (5 агентов = 250k+ токенов). Но подписка Claude Pro ($20/мес) спасает
- Один тим на сессию
- Нет resume для in-process mode

## Вердикт

Для простых задач — overkill. Но для code review, отладки или исследований с разных углов — это **реальная параллелизация с коллаборацией**.
