# Telegram Announcement Writer

Скилл для написания цепляющих анонсов статей в Telegram-канал @maslennikovigor.

## Когда использовать

- Пользователь просит написать анонс статьи для Telegram
- Нужно прорекламировать статью с Habr, VC.ru, TenChat, Pikabu, Telegraph
- Ключевые слова: "анонс", "пост для канала", "анонсировать статью"

## Главный принцип

**Анонс — это не пересказ статьи. Это приманка.**

Задача анонса: заинтересовать → вызвать эмоцию → заставить кликнуть. Читатель должен почувствовать, что **упускает что-то важное**, если не перейдёт по ссылке.

## Платформа: Telegram

**Канал:** @maslennikovigor
**Аудитория:** IT-специалисты, предприниматели, руководители, AI-энтузиасты
**Тон:** Разговорный, энергичный, от первого лица
**Длина:** 500-900 символов (идеал), максимум 1200
**Язык:** Русский

## Обязательный workflow

0. **Загрузи правила живого письма** — invoke `Skill('living-text-style')` ПЕРЕД написанием анонса. Это превентивный слой: пиши сразу живо, без AI-маркеров. Детективный слой (`cleanup-ai-noise` в шаге 6) разберётся с тем, что проскочило. Не пропускай.
1. **Прочитай статью** — выдели 2-3 самых цепляющих факта/числа/инсайта
2. **Найди крючок** — что в статье удивит, шокирует или заденет читателя?
3. **Напиши 3-4 варианта** — разные крючки, разные эмоции
4. **Добавь рекомендацию** — какой вариант лучше и почему
5. **Сохрани в файл** — `articles/telegram-posts/[slug]-announcement.md`
6. **Прогони через `cleanup-ai-noise`** с `platform=telegram-announcement` (см. секцию «Финальная проверка»)
7. **Сгенерируй Angela-гайд** — `articles/pictures/[slug]/ANGELA-PUBLISHING-CHECKLIST.md` (см. секцию «Angela publishing checklist» ниже). Это финальный артефакт цикла — без него ассистент не сможет опубликовать материалы в правильном порядке.
8. **После `/push patch` пришли автору GitHub-ссылку на Angela-гайд** в формате `https://github.com/<owner>/<repo>/blob/<branch>/articles/pictures/[slug]/ANGELA-PUBLISHING-CHECKLIST.md`. Это нужно, чтобы автор мог переслать ссылку Анжеле одним движением, без лазания по папкам репозитория. Шаг ОБЯЗАТЕЛЬНЫЙ — не забудь.

> **Важно про обложки:** генерация PNG-обложек НЕ входит в этот скилл. Промты для обложек создаются в скилле `habr-article` (ФАЗА 4) — он же создаёт папку `articles/pictures/[slug]/cover-prompts.md`. Этот скилл просто **ссылается** на готовые промты в Angela-гайде. Если папки нет — попроси автора сначала запустить `habr-article` для исходной статьи.

## Анатомия цепляющего анонса

```
📌 **[КРЮЧОК — 1 строка, которая останавливает скроллинг]**

[КОНТЕКСТ — 1-2 предложения: почему это важно лично мне]

[ТИЗЕР — 3-5 буллетов: самое вкусное из статьи, но НЕ всё]

[КЛИФФХЭНГЕР — незавершённая мысль, вопрос или интрига]

👉 **Читать:** [ССЫЛКА]

_[ПОДПИСЬ — дополнительная информация курсивом]_
```

## 7 типов крючков (используй разные для вариантов!)

### 1. Шокирующий факт
```
📌 **2.5 часа в день ты тратишь на поиск информации. 23 дня в год — на отвлечения.**

Я решил это починить...
```

### 2. Личная история / Фейл
```
📌 **Забыл про встречу с клиентом. Во второй раз за месяц.**

После этого собрал систему, которая запоминает за меня...
```

### 3. Контринтуитивное утверждение
```
📌 **$500 инвестиций → $2.4M экономии в год. Это не кликбейт.**

Посчитали стоимость AI-моделей при масштабировании...
```

### 4. Вопрос-провокация
```
📌 **Зачем платить $221K/мес за AI, если можно $18.8K?**

Мы нашли способ. 12,000 API-вызовов и 2 недели тестирования...
```

### 5. Результат без объяснения (интрига)
```
📌 **Follow-up rate утроился. Благодаря одному голосовому в день.**

Нет, это не мотивационный бред. Вот как работает...
```

### 6. «Я думал X, оказалось Y»
```
📌 **Думал, Notion решит проблему. Через неделю — свалка из 200 строк.**

Потом понял: проблема не в приложении, а в подходе...
```

### 7. Цифра + эмоция
```
📌 **82% людей вообще не используют инструменты для задач. Я был одним из них.**

Пока не задолбался забывать всё подряд...
```

## Правила тизера (буллеты)

**Показывай самое вкусное, но НЕ раскрывай всё:**

```
✅ Хороший тизер (интригует):
• Почему голос быстрее текста в 3.5 раза — и как я это использую
• Как Todoist превратился в CRM (follow-up rate x3)
• Один вопрос, который можно задать своему «второму мозгу»

❌ Плохой тизер (пересказ):
• Бот транскрибирует голосовые через Deepgram
• Задачи создаются в Todoist с датами и приоритетами
• Стоит $25 в месяц, код открытый
```

**Формулы для буллетов:**
- «Почему X — и как Y» (интрига + обещание)
- «Что случилось, когда я попробовал X» (история)
- «X, о котором никто не говорит» (эксклюзив)
- «Как X превратился в Y» (трансформация)
- Конкретная цифра + неожиданный контекст

## Клиффхэнгер (ОБЯЗАТЕЛЬНО!)

Последняя строка перед ссылкой должна **не закрывать**, а **открывать** вопрос:

```
✅ Хорошие клиффхэнгеры:
• "В статье — полная механика + кейс, который меня самого удивил."
• "Самое интересное — в секции про то, где это НЕ работает."
• "Спойлер: один нюанс чуть не заставил меня всё бросить."
• "Плюс инструкция по установке — если не боишься терминала."

❌ Плохие (закрывают интерес):
• "В статье всё подробно описано."
• "Рекомендую прочитать."
• "Подробнее по ссылке ниже."
```

## Адаптация под платформу статьи

### Habr (техническая аудитория)
- Упоминай технические детали: стек, архитектуру, метрики
- «Разбираю с кодом и схемами»
- «Для тех, кто хочет повторить — есть конфиги и команды»

### VC.ru (бизнес-аудитория)
- Фокус на деньгах: ROI, экономия, окупаемость
- «Посчитали ROI — цифры удивили»
- «Кейс с конкретными суммами»

### TenChat (деловая сеть)
- Экспертный тон, кейсы, нетворкинг
- «Написал для предпринимателей — без технического жаргона»
- «Кейс из моей практики»

### Pikabu (широкая аудитория)
- Юмор, простота, история
- «Написал по-человечески, без умничания»
- «С историей моего позора в начале»

### Telegraph (Telegram-аудитория)
- Быстрое чтение, мобильный формат
- «Читается за 5 минут»
- «Короткий разбор без воды»

## Форматирование

### Emoji (строго дозированно)
- 📌 — начало поста (заголовок-крючок)
- 👉 — призыв к действию (ссылка)
- • — буллеты в тизере
- _курсив_ — подпись, дополнительная информация

**Максимум 3-4 emoji на пост.** Больше — выглядит как спам.

### Markdown
- `**жирный**` — крючок, ключевые фразы, CTA
- `_курсив_` — подпись, дополнительная информация
- Ссылки: просто URL (Telegram сам делает превью)

### Хэштеги
- **1-3 штуки**, не больше
- Среднечастотные: `#AI`, `#автоматизация`, `#разработка`
- НЕ использовать высокочастотные (#бизнес, #маркетинг — утонешь)
- Ставить в конце поста, НЕ в середине текста

## Анти-AI напоминание

Полный каталог запрещённых паттернов (27 категорий + штампы проекта + специфика анонсов — пересказ вместо хука, пустые призывы, мёртвые вступления) и автоматическая чистка — в агенте `ai-text-checker`. Запуск — после написания всех вариантов через skill `cleanup-ai-noise` с параметром `platform=telegram-announcement` (см. ниже секцию «Финальная проверка»). Здесь — только напоминания при написании:

- Никаких «Друзья!», «Коллеги!», «Дорогие подписчики!»
- Никаких «Рад поделиться», «Опубликовал статью», «Написал материал»
- Не пересказывай статью — давай хук, не TL;DR
- Никаких «Подробнее по ссылке», «Рекомендую к прочтению» — вместо них клиффхэнгер
- Никаких «Важно отметить», «Существенно/значительно/кардинально»

### Обязательно

- **Крючок в первой строке** — останавливает скроллинг
- **Эмоция** — удивление, узнавание, интрига, «я тоже так делаю»
- **Незавершённость** — читатель должен ХОТЕТЬ узнать продолжение
- **Конкретика** — цифры, имена, даты вместо абстракций
- **Первое лицо** — «я сделал», «у меня», «меня зацепило»
- **Один пост = одна статья** — не мешать анонсы

## Финальная проверка (ОБЯЗАТЕЛЬНО!)

После написания всех вариантов и выбора рекомендуемого — запусти skill `cleanup-ai-noise` с параметром `platform=telegram-announcement`. Скилл сохранит выбранный вариант в `.tmp/current/articles/`, прогонит агента `ai-text-checker` (27 паттернов + штампы проекта + специфика анонсов — пересказ вместо хука, отсутствие контекста оригинала) и вернёт отчёт с правками + спорные места. Только после автоправки — публикуй анонс в канал.

## Время публикации

**Лучшее время (МСК):**
- Будни: **13:00-16:00** (дневной пик) или **18:00-22:00** (вечерний пик)
- Выходные: **23:00 пятницы — 01:00 субботы** (максимум просмотров)

**Худшее время:**
- 06:00 утра (любой день)
- 10:00 утра в будни
- Ночь среда-четверг

## Частота

- **3-5 постов в неделю** (оптимально)
- Не больше 1 анонса в день
- Не больше 3 постов любого типа в день
- Рекламного контента — не более 20-30%

## Angela publishing checklist (финальный шаг — ОБЯЗАТЕЛЬНО)

После того как Telegram-анонс готов и прошёл `cleanup-ai-noise`, **обязательно** сгенерируй памятку для ассистента Анжелы. Она нужна, чтобы Анжела опубликовала цикл из 3-4 платформ в правильном порядке без вопросов.

### Куда сохранять

```
articles/pictures/[article-slug]/ANGELA-PUBLISHING-CHECKLIST.md
```

Та же папка, где лежат промты обложек и сгенерированные PNG. Один цикл — одна папка.

### Когда применять стандартный шаблон, а когда — особый

**Стандартный шаблон** (90% случаев) — статья опубликована на Habr/TenChat/Pikabu, к ней добавляется Telegram-анонс со ссылкой на Habr-версию. Бери шаблон ниже и заполняй.

**Особый шаблон** — если в цикле есть нестандартные элементы:
- PDF/файл-лид-магнит, который пинится в канал и на него ссылаются статьи
- Сериальная публикация (часть 1, часть 2, часть 3 — каждая ссылается на следующую)
- Кросс-платформенный приоритет (например, основная — VC.ru, а не Habr)

В особых случаях бери стандартный шаблон как основу и явно опиши, что отличается.

### Стандартный шаблон Angela-гайда

Заполни шаблон ниже подставив реальные значения вместо `[плейсхолдеров]`. Не оставляй квадратных скобок в финале.

```markdown
# Памятка для Анжелы: публикация цикла «[Краткое название цикла]»

Анжела, привет. Готов цикл из [N] материалов про [одна-две фразы — о чём статья и почему её сейчас публикуем].

Если что-то непонятно — пиши, разберёмся.

---

## Что публикуем

[Одно-два предложения сути темы.]

**[N] материалов:**

1. **Habr** — основная статья (~[X] знаков, [технический разбор / обзор / новость / кейс])
2. **TenChat** — деловая версия (~[X] знаков, для предпринимателей и руководителей)
3. **Pikabu** — народная версия (~[X] знаков, на «ты», [с самоиронией / с провокацией / с историей])
4. **Telegram-анонс** — анонс Habr-статьи (3-4 варианта в файле, рекомендуемый отмечен)

Все файлы — в свежем коммите, после `git pull` будут у тебя.

## Порядок публикации

### Шаг 1. Habr (первой — на неё ссылается Telegram-анонс)

Файл: `articles/habr/[slug].md`

- **Заголовок**: «[заголовок из frontmatter title]»
- **Подзаголовок** (если редактор предлагает): «[subtitle из frontmatter, если есть]»
- **Хабы**: [hubs из frontmatter]
- **Теги**: [tags из frontmatter]
- **Превью для ленты**: взять из frontmatter `feed_preview` (тот текст, что заверстан в YAML вверху файла)
- **Обложка**: из папки `articles/pictures/[slug]/`. Лучшее для Habr — [Prompt 1 / Prompt 3 — указать, какой по смыслу подходит, опираясь на секцию «Адаптация под платформы» в cover-prompts.md]
- **Опубликовать → СКОПИРУЙ URL опубликованной статьи на Habr**, нужен для Шага 4.

### Шаг 2. TenChat

Файл: `articles/tenchat/[slug].md`

- **Заголовок**: «[заголовок]»
- **Теги**: [3 тега, как обычно для TenChat]
- **Обложка**: [рекомендуемый промт из cover-prompts.md, обычно инфографика]
- **Особенность**: на TenChat нет markdown-таблиц, нет блоков кода и нет markdown-заголовков. У меня в файле есть `##` для удобства чтения — при копировании в редактор замени их на встроенные заголовки или просто выдели жирным.
- Опубликовать.

### Шаг 3. Pikabu

Файл: `articles/pikabu/[slug].md`

- **ВАЖНО**: на Pikabu нет markdown-таблиц, нет блоков кода и нет заголовков `##`. У меня в файле есть `##` для удобства чтения — при копировании в редактор замени их на обычный жирный текст или встроенный «Заголовок».
- **Заголовок**: «[заголовок, до 140 символов]»
- **Теги**: [теги из frontmatter]
- **Обложка**: [рекомендуемый промт — обычно метафорический]
- Опубликовать.

### Шаг 4. Telegram-анонс (со ссылкой на Habr)

Файл: `articles/telegram-posts/[slug]-announcement.md`

В файле 3-4 варианта анонса. Берём **рекомендуемый** (отмечен в файле). Это первый блок после `## Вариант [N]`.

- В тексте есть плейсхолдер `[LINK]` — заменить на URL Habr-статьи из Шага 1.
- Опубликовать в @maslennikovigor.
- **Время публикации**: будни 13:00–16:00 МСК (дневной пик) или 18:00–22:00 МСК.

## Что важно проверить перед публикацией каждой статьи

1. **Дата в frontmatter актуальна** (стоит [дата из frontmatter] — поправь, если будем публиковать в другой день).
2. **На Habr** — превью для ленты вставлено в отдельную секцию редактора, не в основной текст.
3. **На Pikabu** — markdown-заголовки `##` приведены к рабочему виду, нет markdown-таблиц.
4. **На TenChat** — то же самое: убрать markdown-разметку заголовков, оформить через встроенный редактор.
5. **В Telegram-анонсе** — `[LINK]` заменён на URL Habr-статьи.

[Если в цикле есть особые риски — например, технические термины, которые нельзя править, или якорные цитаты — добавь их сюда отдельным пунктом.]

## Если что-то пошло не так

- Если опубликовать сразу не получается (например, заблокировал антифрод TenChat или Habr ушёл в pre-moderation) — ничего не правь в файлах, напиши мне, разберёмся.
- Если в тексте статьи нашла очевидную опечатку или фактическую ошибку — исправь прямо в редакторе платформы перед публикацией, а потом скажи мне, я внесу в репо.
- Если не уверена, какую обложку выбрать — смотри секцию «Адаптация под платформы» в `cover-prompts.md` той же папки.
- Если есть сомнения по любому из шагов — перечитай этот файл целиком ещё раз. Если всё равно непонятно — пиши.

Спасибо!
```

### Что подставлять при заполнении

Для каждой статьи цикла открой файл и возьми:

- `title`, `subtitle`, `tags`, `hubs`, `feed_preview`, `length` — из frontmatter
- Размеры (~X знаков) — округляй до сотен
- Какой Prompt какой платформе — из секции «Адаптация под платформы» в `cover-prompts.md`
- Slug — берётся из имени файла статьи (без расширения)

### Особенности этого цикла (опциональная секция)

Если в текущем цикле есть нестандартные элементы (PDF-лид-магнит, серия из нескольких статей, нестандартный порядок, шутки/отсылки которые нельзя править), добавь после блока «Если что-то пошло не так» секцию `## Особенности именно этого цикла` и перечисли их.
